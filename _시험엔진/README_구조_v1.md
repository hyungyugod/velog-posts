# 시험 학습엔진 — 베이스+프로파일 구조 v1.3 (2026-08-29)

> **이 폴더(velog-posts/_시험엔진/)가 모든 퀴즈·오답 자동화의 단일 정본 저장소다.**
> 이 엔진군의 공식 명칭은 **HG Infinite Recall System (HG 무한복습체계)** — 학습 메커니즘 정본은 `공부루틴_OS_v1.md`.
> 정본을 velog-posts 밖(ai-guidelines 등)에 두지 않는 이유: **스케줄 세션은 태스크가 '생성된 시점'에 연결돼 있던 폴더만 마운트한다.** 2026-08-25 아침 공인중개사 데일리퀴즈 태스크(구 daily-quiz-gongin)가 ai-guidelines를 못 읽어 자동 실행이 실패한 실사고의 교훈. 모든 작업이 velog-posts를 반드시 쓰므로, 정본도 여기에 두면 의존 폴더가 1개로 줄어 이 실패 계급이 사라진다.

**참조 파일 계급** (2026-08-28 신설): `참조_*`는 절차(베이스)도 파라미터(프로파일)도 아닌 **형식·소재 사전**이다. 프로파일이 필독을 지시하면 실행자는 베이스 → 프로파일 → 참조 순으로 정독한다. 우선순위는 프로파일 > 참조(형식 상세) > 베이스.

**트랙 분할 패턴** (2026-08-25): 한 시험의 1차/2차처럼 형식이 다른 갈래는 **트랙별 프로파일**로 분리한다 — EXAM_DIR은 중첩 경로(`법무사/1차`), 산출물·원장·결과 파일명은 트랙별 완전 분리, **노트 폴더만 공유**(`법무사/` 최상위)하고 파일명의 `-2차-` 유무가 트랙 스위치다. 트랙 하나 = 시험 하나로 취급해 스케줄러 3개씩 가진다.

## 실행 규칙 (모든 스케줄러 공통)

1. 스케줄드 태스크의 프롬프트는 **위임문만** 갖는다: "베이스 X + 프로파일 Y를 읽고 실행하라."
2. 실행자는 **베이스 → 프로파일 순으로 둘 다 정독**한 뒤 실행한다.
3. **우선순위: 프로파일 > 베이스 > 태스크 위임문.** 베이스의 `⟨프로파일: KEY⟩` 슬롯은 프로파일의 같은 KEY 항목으로 채운다. 프로파일에 없는 KEY를 만나면 지어내지 말고 "프로파일 미정의: KEY"를 보고하고 그 부분만 생략한다.
4. 검증 스크립트는 **프로파일에 완결본으로 존재**한다(추상화하지 않는다 — 정확성이 우선). 베이스는 "프로파일의 검증 스크립트를 그대로 실행, 통과까지 반복"만 명한다.

## 시험 1개 = 스케줄러 3개 (사이클 독립)

| 작업 | 베이스 | 공인중개사 | 법무사 1차 | 법무사 2차 |
|---|---|---|---|---|
| 오답 파이프라인 | 베이스_오답파이프라인 | `gongin-odap-quiz` **월~토** 08:40 | `bupsa-1cha-odap-quiz` 평일 08:55 | `bupsa-2cha-odap-quiz` 평일 08:50 |
| 데일리퀴즈 | 베이스_데일리퀴즈 | `gongin-daily-quiz` **월~토** 09:07 | `bupsa-1cha-daily-quiz` 화·목 09:20 | `bupsa-2cha-daily-quiz` 화·목 09:15 (11/1 평일 전환은 두 트랙 공통) |
| 주간 리포트 (월) | 베이스_주간리포트 | `gongin-weekly-report` 07:09 | `bupsa-1cha-weekly-report` 07:40 | `bupsa-2cha-weekly-report` 07:30 |

이 밖에 **시험 횡단 스케줄러 1개**: `anki-weekly-deck` 월 08:00 — 원자카드 주간 덱 (베이스_앙키덱_v1, 산출: `_시험엔진/anki/출고/`, 맥락: `공부루틴_OS_v1.md` §6).

세 사이클의 파일·원장·결과는 **완전 분리**되며 교차 참조 금지 (프로파일의 RESULT_GLOB·EXAM_DIR이 경계). 법무사 1차/2차는 노트 폴더만 공유하며, 1차 노트가 아직 없는 동안 1차 사이클은 "스킵/듀 0" 보고만 하는 게 정상이다.

## 새 시험 추가 절차 (예: 간호학 복학 시)

1. **프로파일 작성**: `프로파일_간호학_v1.md` — 기존 프로파일을 템플릿 삼아 [공통 파라미터]·[데일리퀴즈]·[오답퀴즈]·[주간리포트] 섹션과 검증 스크립트를 채운다 (간호학 특성: 계산형=투약 계산, 사례형=간호과정 등은 프로파일 특칙으로).
2. **폴더 스캐폴드**: `velog-posts/간호학/{데일리퀴즈,오답퀴즈,claude_ox_오답/{_inbox,_raw,_ledger}}` 생성. 데일리퀴즈/오답퀴즈에 템플릿 사본 배치(기존 시험 템플릿에서 제목·결과 파일명 `간호학_오답_${QUIZ_DATE}[-RQ].json`·subject만 교체). `_ledger/build_ledger.py`는 법무사판을 복사해 RESULT_GLOB·과목맵만 교체 (fsrs_vendor 폴더 포함 복사 필수).
3. **스케줄러 3개 등록**: 반드시 **velog-posts가 연결된 세션에서** create_scheduled_task 실행(마운트 상속 규칙!). 등록 직후 **각 태스크를 한 번 수동 실행(Run now)** 해서 도구 승인을 사전 부여한다 — 자동 실행은 승인 질문에 답할 사람이 없다.
4. INDEX(`ai-guidelines/50_스케줄-자동화/데일리퀴즈_지침_INDEX.md`)에 행 추가.

## 시험 종료 절차 (예: 공인중개사 2026-10-31 이후)

1. 해당 시험의 스케줄러 3개를 `enabled: false`로 전환 (삭제하지 않는다 — 이력·재활성 대비).
2. 프로파일 머리에 `[종료: YYYY-MM-DD]` 표기. 폴더·원장은 보존(콘텐츠 소재·복습 자산).
3. 카톡푸시(launchd) 등 시험 전용 외부 잡이 있으면 함께 disable (공인중개사: kakao_push 4잡).
