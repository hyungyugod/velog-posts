"중요해 보여서" 넣는 경로는 없다 ⑥ 검증 통과 전 종료 금지.**

## 2. 카드 문안 작성 (원자화)

- 형식: cloze 우선. `도시개발조합 설립인가 동의: 토지면적 {{c1::3분의 2}} 이상 + 토지소유자 총수 {{c2::2분의 1}} 이상`
- basic은 "앞면 질문 1줄 → 뒷면 사실 1줄"이 자연스러운 것만 (예: 두문자 전개).
- 앞면에 맥락 1줄 필수 — 카드만 보고 무엇의 이야기인지 알게.
- 한 개념에서 사실이 2개면 카드 2장으로 쪼갠다 (cloze c1·c2는 같은 문장 안 동시 암기가 자연스러울 때만).
- 함정 대비: 원문 expl의 혼동 대상("농공단지 70%·산업단지 80%와 혼동")은 뒷면 보충(back)에 1줄로.
- key: 원장 항목은 `conceptKey` 그대로 / ★·백지 구멍은 `과목-소제목-요지` 짧게 신규 부여. 한 conceptKey에서 카드를 여러 장으로 쪼갤 때 둘째 장부터 `conceptKey-접미사`로 분기한다(key 중복 방지·guid 안정 — 예: `부동산공시법 1-3-관상수`).
- deck: `자격증::공인중개사::{과목}` / `자격증::법무사::{과목}` / tags: 시험명·과목·원천(상습/강조/백지).

## 3. TSV → 빌드

- `$AK/카드_{오늘날짜}.tsv` 작성 — 컬럼: `deck / type(basic|cloze) / front / back / tags(공백 구분) / src(출처 노트·원장 파일명) / key`. 필드 안 탭·줄바꿈 금지(줄바꿈은 `<br>`).
- 빌드: `pip install genanki --break-system-packages` 후 `python3 "$AK/build_apkg.py" "$AK/카드_{오늘날짜}.tsv"` → `$AK/출고/{오늘날짜}.apkg`.
- 특집 덱(별도 TSV)은 `카드_{날짜}-{특집명}.tsv`로 만들면 출력도 `{날짜}-{특집명}.apkg`로 분리된다 (빌더가 접미사 보존 — 2026-08-26 덮어쓰기 실사고 후 근본 수정).
- 빌더가 검증까지 수행(카드 수·cloze 문법·key 중복·빈 값 — FAIL 시 exit 1). FAIL이면 TSV 수정 후 재실행, 통과 전 종료 금지.
- **빌더 스크립트 수정 금지** (모델 ID 2종은 불가침 — 바꾸면 기존 카드 학습 이력이 끊긴다).

## 4. 검수리포트 (게이트 — 생략 불가)

`$AK/출고/검수_{오늘날짜}.md` 생성:
- 머리: 총 카드 수 · 시험/과목별 분포 · **원천별 분포(상습 / ★★ / ★ / 백지)** · **표식 실측 표**(대상 노트별 `★★`·`★` 줄 수 — §1 ②에서 센 값) · 상한 집계(상습+백지+★ ≤ 25, ★★는 제외)
- 본문: 카드 전문 표 — `# | deck | 앞면 | 뒷면 | 원천 | 표식 원문 줄 | src`
  - **`표식 원문 줄`은 원천이 ★★·★인 카드에 필수 (v1.4 게이트)** — 노트에서 표식이 붙은 그 줄을 **그대로 인용**한다(요약·재작성 금지). 인용을 못 대는 카드는 강조 레인 탈락 → 상한 안 소재로 재분류하거나 제외하고, 꼬리에 사유를 적는다. 상습·백지 원천은 `—`.
- 꼬리: 상한 초과로 잘라낸 후보 목록(다음 주 이월 — ★가 먼저 잘린다), 카드화 보류 항목(확인 필요 사유), **강조 레인 탈락 항목(표식 인용 불가 사유)**

## 6. 숫자 총정리 갱신 — n: 태그 주간 시퀀스 (v1.1)

덱 작업(§1~5)을 마친 뒤 같은 실행에서 이어서 한다. **숫자·날짜·기간은 흩어지면 못 외운다** — 사용자가 `n:`을 붙인 항목을 매주 시험별 총정리본에 통합한다.

1. **수집**: 각 활성 시험폴더 최상위 `20*.md` 중 **mtime −7일** 정리본에서 **줄머리의 `n:`**(항목·줄 맨 앞, 불릿 뒤 포함)이 붙은 라인 전부 grep — 문장 중간의 `n:`은 표식이 아니다. 원문 필기의 `:n` 오기는 코어엔진이 정리본 생성 시 `n:`으로 정규화해 승계하므로, 여기서는 정규화된 `n:`만 찾으면 된다. **대문자 `N:`은 수식 변수 표기('N: 공급자 수' 실측)와 충돌하므로 정규화하지 않는다 (v1.3).**
2. **통합 대상 정본**:
   - 공인중개사 → `공인중개사/공인중개사_날짜기간_총정리_v1.md`
   - 법무사 → `법무사/법무사_숫자체계_v1.md` — **첫 n: 항목 발견 시 같은 양식(과목별 표 + 숫자 역인덱스 + 충돌 섹션)으로 생성**, 그 전엔 스킵 보고
3. **통합 규칙**: ① 신규 항목만 추가(기존 항목 중복 금지 — 항목명 대조) ② 해당 과목 표에 `항목 | 기산일 | 기간·수치 | 혼동 주의` 행 추가 ③ **숫자 역인덱스의 해당 숫자 버킷에도 편입** ④ 기존 항목과 수치가 충돌하면 본문에 넣지 말고 `⚠️ 충돌` 섹션에 나란히 기록 후 보고에 명시 ⑤ 원문에 없는 내용·기산일 추정 금지(없으면 `—`)
4. **보고**: 시험별 신규 N건 · 충돌 N건 · 역인덱스 최밀집 숫자 변동 여부 1줄.
5. n: 항목의 Anki 편입은 자동이 아니다 — `!`가 같이 붙은 항목만 §1 의무 편입 규칙을 따른다 (카드 폭증 방지).

## 7. 특집 덱 (온디맨드 — v1.3)

주간 정규 덱과 별개로, 한 주제를 몰아서 원자화하는 덱. 이미 두 차례 출고된 실무(세율 특집 27노트·날짜 특집 19노트)를 규격화한 것.

- **트리거**: **사용자 요청 시에만** 생성한다. 스케줄러가 자동으로 만들지 않는다.
- **파일명**: `카드_YYYY-MM-DD-주제특집.tsv` → 출력 `YYYY-MM-DD-주제특집.apkg` (§3의 접미사 보존 규칙 준용 — 정규 덱을 덮어쓰지 않는다).
- **검수 리포트**: §4 양식 그대로 (카드 전문 표 + `src` 열 필수).
- **상한**: 주간 25장 상한과 **별도**로 센다 (의무 편입 아님 — 정규 덱의 몫을 잠식하지 않는다).
- **원천·금지 규칙**: 실행원칙 ①②③ 동일 적용 — 원문에 없는 내용 금지, "(확인 필요)"·⚠️ 금지, 원문 미명시 조문번호·수치 제외.
