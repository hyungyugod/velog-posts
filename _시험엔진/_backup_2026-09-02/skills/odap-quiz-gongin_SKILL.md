# odap-quiz-gongin (위임문 — 온디맨드판)

"공인중개사 오답 재도전 퀴즈" 작업이다. 전부 한국어로 진행한다. ① Downloads 결과 JSON 수거 → ② 오답원장(FSRS) 갱신 → ③ 듀 큐 기반 재도전 퀴즈 생성 — 이 순서가 곧 "퀴즈 만들 때 우선 오답원장 반영"이다. 절차의 정본은 엔진 파일이고, 이 문서는 위임문과 온디맨드 특칙만 담는다.

## 0. 경로 (마운트 지연 대비 — 반드시 재시도)

```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break; echo "velog-posts 대기... ($i/5)"; sleep 5
done
```

실패 시 아무것도 생성하지 말고 "velog-posts 미연결 — 폴더 연결 필요"를 보고하고 종료한다.

## 1. 엔진 정독 (실행 전 필수)

`$ROOT/_시험엔진/`의 두 파일을 순서대로 전부 읽는다: ① `베이스_오답파이프라인_v1.md` ② `프로파일_공인중개사_v1.md`. (한글 경로는 bash cat이 확실하다.)
하나라도 없으면 생성하지 말고 "엔진 파일 부재 — 경로 확인 필요"를 보고하고 종료한다. 우선순위: 프로파일 > 베이스 > 이 문서. 엔진·템플릿·build_ledger.py 수정 절대 금지.

## 2. 실행

베이스_오답파이프라인 §0~§5 전체를 프로파일_공인중개사 값으로 그대로 실행한다 (수거는 `cp -n`·RESULT_GLOB 그대로, Downloads는 읽기 전용, 원장 갱신 후 프로파일의 대시보드 실행 포함).

## 3. 온디맨드 특칙

- 요일 무관 실행("평일 아침"은 맥 스케줄 맥락일 뿐). 항상 오늘 하루치만.
- **듀 0이면 미생성이 정답** — "듀 0 — 오답퀴즈 없음" 1줄 보고로 끝낸다. 문항을 채우려고 다른 원천을 끌어오지 않는다(FSRS 마감 도래분만이 원천).
- 오늘분 `-RQ` html이 이미 있으면 수거·원장 갱신까지만 수행하고 **기존 파일을 present_files로 제시**한다(덮어쓰기 금지 — 사용자가 명시적으로 재생성·덮어쓰기를 지시한 경우만 예외).
- 맥 스케줄러가 도는 토요일 오전(08:40 즈음)과 겹치면 동기화 충돌 위험 — 그 시간대면 잠시 뒤 실행을 권한다.
- 마무리 안내 1줄: 풀고 저장한 `-RQ` 결과 JSON은 다음 실행 때 자동 회수되어 졸업·상습·재도전 판정에 반영된다.
