# daily-quiz-gongin (위임문 — 온디맨드판 v2.1)

"공인중개사 데일리 문제지"를 사용자가 원할 때 생성하는 작업이다. 전부 한국어로 진행한다.
맥의 월~토 아침 스케줄러와 같은 엔진을 쓰는 온디맨드 실행이다 — 절차의 정본은 엔진 파일이고, 이 문서는 위임문과 온디맨드 특칙만 담는다.

## 0. 경로 (마운트 지연 대비 — 반드시 재시도)

```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break; echo "velog-posts 대기... ($i/5)"; sleep 5
done
```

실패 시 아무것도 생성하지 말고 "velog-posts 미연결 — 폴더 연결 필요"를 보고하고 종료한다.

## 1. 엔진 정독 (생성 전 필수)

`$ROOT/_시험엔진/`의 두 파일을 순서대로 전부 읽는다: ① `베이스_데일리퀴즈_v1.md` ② `프로파일_공인중개사_v1.md`. (한글 경로는 bash cat이 확실하다.)
하나라도 없으면 생성하지 말고 "엔진 파일 부재 — 경로 확인 필요"를 보고하고 종료한다. 우선순위: 프로파일 > 베이스 > 이 문서. 엔진·템플릿·build_ledger.py 등 스크립트 파일은 절대 수정하지 않는다.

## 2. 오답원장 선행 갱신 (온디맨드 특칙 ①)

데일리퀴즈 생성 전에 `$ROOT/_시험엔진/베이스_오답파이프라인_v1.md`의 **§0~§2만** 프로파일_공인중개사 값으로 수행한다 — Downloads 결과 JSON 수거(`cp -n`, RESULT_GLOB 그대로) → `build_ledger.py --ingest` → 프로파일에 정의된 대시보드.
이유: 이 컴퓨터에서 푼 퀴즈의 결과 JSON은 이 컴퓨터의 Downloads에만 있다. 이 단계가 그것을 velog-posts 원장으로 회수하는 유일한 경로다.
오답파이프라인의 §3(오답 재도전 퀴즈 생성)은 하지 않는다 — 그건 odap-quiz-gongin 몫이다. 수거 0건·원장 오류가 나도 보고만 하고 **이 문서 §3(데일리퀴즈 생성)으로** 진행한다 — 데일리퀴즈는 원장을 출제에 쓰지 않는다(재도전 금지 구조).

## 3. 데일리퀴즈 생성

베이스_데일리퀴즈 §0~§6(§5.5 푸시 페이로드 포함)을 프로파일 값으로 채워 그대로 실행한다.

## 4. 온디맨드 특칙 ②③

- 요일 무관 실행("평일 아침"은 맥 스케줄 맥락일 뿐). 단 "오늘 하루치 1개만" 가드는 그대로 — 밀린 과거 날짜분 생성 금지.
- 오늘분 html이 이미 있으면(맥 스케줄러가 먼저 생성) 새로 만들지 말고 **그 파일을 present_files로 제시**한다 — 사용자는 지금 풀 문제지를 원해서 이 스킬을 불렀다. §2 수거·원장 갱신은 그래도 수행한다.
- 맥 스케줄러가 도는 토요일 오전(08:40~09:10 즈음)과 겹치면 같은 날짜 이중 생성·동기화 충돌 위험 — 그 시간대면 잠시 뒤 실행을 권한다.
- 마무리 안내 1줄: 풀고 저장한 결과 JSON(Downloads)은 다음 퀴즈 스킬 실행 때 자동으로 원장에 회수된다.
