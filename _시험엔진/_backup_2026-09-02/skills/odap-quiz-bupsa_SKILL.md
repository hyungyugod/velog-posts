# odap-quiz-bupsa (위임문 — 온디맨드판)

"법무사 오답 재도전 퀴즈" 작업이다. 전부 한국어로 진행한다. ① Downloads 결과 JSON 수거 → ② 오답원장(FSRS) 갱신 → ③ 듀 큐 기반 재도전 퀴즈 생성 — 이 순서가 곧 "퀴즈 만들 때 우선 오답원장 반영"이다. 절차의 정본은 엔진 파일이고, 이 문서는 위임문과 온디맨드 특칙만 담는다.

## 0. 경로 (마운트 지연 대비 — 반드시 재시도)

```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break; echo "velog-posts 대기... ($i/5)"; sleep 5
done
```

실패 시 아무것도 생성하지 말고 "velog-posts 미연결 — 폴더 연결 필요"를 보고하고 종료한다.

## 1. 트랙 구조 — 한 번 호출로 두 트랙 처리

실행 순서: **① 2차 트랙**(`프로파일_법무사2차_v1.md`, EXAM_DIR `법무사/2차`) → **② 1차 트랙**(`프로파일_법무사1차_v1.md`, EXAM_DIR `법무사/1차`). 트랙마다 §2~§3을 독립 수행한다.
1차는 원장 미가동(결과 0건) 동안 exit 2 보고 후 그 트랙 종료가 정상이다. 트랙 간 파일·원장 교차 절대 금지 — 남의 원장으로 이 트랙 퀴즈를 만들면 안 된다.

## 2. 엔진 정독 (트랙마다, 실행 전 필수)

`$ROOT/_시험엔진/`에서 순서대로 전부 읽는다: ① `베이스_오답파이프라인_v1.md` ② 해당 트랙 프로파일 ③ 프로파일이 지시한 참조 파일(2차: `참조_법무사2차_문형사전_v1.md` — 감점 패턴이 변형 출제 우선 재료 / 1차: `참조_법무사1차_기출문형_v1.md` — 함정 패턴표). (한글 경로는 bash cat이 확실하다.)
베이스·프로파일 중 하나라도 없으면 그 트랙은 생성하지 말고 "엔진 파일 부재"를 보고한다. 우선순위: 프로파일 > 참조 > 베이스 > 이 문서. 엔진·템플릿·build_ledger.py 수정 절대 금지.

## 3. 트랙 실행

베이스_오답파이프라인 §0~§5 전체를 해당 트랙 프로파일 값으로 그대로 실행한다. 수거 직전에 `mkdir -p "$BASE/_inbox" "$BASE/_raw"`를 실행한다 — 1차 스캐폴드에 이 두 폴더가 아직 없어, 없으면 `cp -n`이 조용히 실패해 결과 JSON이 회수되지 않는다(README의 스캐폴드 규격 복원일 뿐 새 구조가 아니다).
주의: 검증은 프로파일이 정한 대로 — 1차는 베이스 공통 스크립트를 **실행하지 않고** 프로파일의 완결 스크립트로 대체(5지+단답 승격 계약), 2차는 베이스 공통 스크립트 + 2차 전용 추가 검증 둘 다 통과.

## 4. 온디맨드 특칙

- 요일 무관 실행("평일 아침"은 맥 스케줄 맥락일 뿐). 항상 오늘 하루치만.
- **듀 0이면 미생성이 정답** — "듀 0 — 오답퀴즈 없음" 1줄 보고로 끝낸다. 문항을 채우려고 다른 원천을 끌어오지 않는다(FSRS 마감 도래분만이 원천).
- 오늘분 `-RQ` html이 이미 있으면 수거·원장 갱신까지만 수행하고 **기존 파일을 present_files로 제시**한다(덮어쓰기 금지 — 사용자가 명시적으로 재생성·덮어쓰기를 지시한 경우만 예외).
- 맥 스케줄러가 도는 평일 오전(08:50~08:55 즈음)과 겹치면 동기화 충돌 위험 — 그 시간대면 잠시 뒤 실행을 권한다.
- 마무리 안내 1줄: 풀고 저장한 `-RQ` 결과 JSON은 다음 실행 때 자동 회수되어 졸업·상습·재도전 판정에 반영된다.

## 핵심 가드 (엔진과 동일)

원 문제 복사 금지 — 같은 개념 다른 각도로 변형 출제 / conceptKey·retryOf는 듀 항목 값 그대로(원장 매칭 키 — 변형 금지) / 듀 큐 재정렬 금지·상위 N개만 / **2차는 전 문항 단답** / **1차는 5지선다 기본 + 단답 승격(2026-09-01)**: 반복 실패 개념(상습 ∨ 재도전실패≥1 ∨ 틀림≥3)은 단답형으로 — 최대 5문·듀 큐 순서 상위부터, 정본은 베이스 §3-2·프로파일 1차 v2.0 / **놓친 포인트 조준**: 듀 항목 `missedTop`이 있으면 그 포인트를 정면으로 겨냥(1문항 1포인트, 없으면 종전 변형 각도) / **원인 라우팅(2026-09-01 밤)**: 듀 항목 `causeTop`(본인이 채점 후 고른 오답 원인)이 있으면 각도를 그것에 맞춘다 — 개념부재→정면, 혼동→판별식·상대 배치, 함정→같은 유형 변형, **실수→각도 변경 없음(개념 문제로 위장 금지)**. missedTop은 소재·causeTop은 각도(베이스 §3-2) / 오답 데이터는 결과 JSON·원장에 있는 것만(지어내기 금지) / 개정법 필터 적용 / 템플릿 JS·CSS 수정 금지 / 검증 통과 전 종료 금지 / 다른 시험·다른 트랙 파일 불가침.
