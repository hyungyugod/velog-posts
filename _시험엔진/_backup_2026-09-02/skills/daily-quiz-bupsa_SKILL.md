# daily-quiz-bupsa (위임문 — 온디맨드판)

"법무사 데일리 문제지"를 사용자가 원할 때 생성하는 작업이다. 전부 한국어로 진행한다.
맥의 화·목 스케줄러와 같은 엔진을 쓰는 온디맨드 실행이다 — 절차의 정본은 엔진 파일이고, 이 문서는 위임문과 온디맨드 특칙만 담는다.

## 0. 경로 (마운트 지연 대비 — 반드시 재시도)

```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break; echo "velog-posts 대기... ($i/5)"; sleep 5
done
```

실패 시 아무것도 생성하지 말고 "velog-posts 미연결 — 폴더 연결 필요"를 보고하고 종료한다.

## 1. 트랙 구조 — 한 번 호출로 두 트랙 처리

법무사는 2차(주관식 단답)·1차(5지선다 객관식)를 별개 시험처럼 돌린다 — 노트 폴더(`법무사/` 최상위)만 공유하고 파일명의 `-2차-` 유무가 트랙 스위치, 산출물·원장은 `법무사/2차`·`법무사/1차`로 완전 분리.
실행 순서: **① 2차 트랙**(`프로파일_법무사2차_v1.md`) → **② 1차 트랙**(`프로파일_법무사1차_v1.md`). 트랙마다 §2~§3을 독립 수행한다.
1차는 노트 0개면 "스킵 — 원천 없음" 1줄 보고가 정상(오류 아님). 1차 노트가 생기면 이 스킬 수정 없이 자동 가동된다. 트랙 간 파일 교차 절대 금지.

## 2. 엔진 정독 (트랙마다, 생성 전 필수)

`$ROOT/_시험엔진/`에서 순서대로 전부 읽는다: ① `베이스_데일리퀴즈_v1.md` ② 해당 트랙 프로파일 ③ 프로파일이 필독 지시한 참조 파일(2차: `참조_법무사2차_문형사전_v1.md` / 1차: `참조_법무사1차_기출문형_v1.md`). (한글 경로는 bash cat이 확실하다.)
베이스·프로파일 중 하나라도 없으면 그 트랙은 생성하지 말고 "엔진 파일 부재"를 보고한다. 우선순위: 프로파일 > 참조 > 베이스 > 이 문서. 엔진·템플릿·스크립트 수정 절대 금지.

## 3. 트랙 실행 = 원장 선행 갱신 + 데일리 생성

**(a) 원장 선행 갱신** — `베이스_오답파이프라인_v1.md`의 **§0~§2만** 해당 트랙 프로파일 값으로 수행한다(Downloads 결과 JSON 수거 `cp -n` → `build_ledger.py --ingest`. 2차의 레거시 수거 특칙도 프로파일대로).
수거 직전에 `mkdir -p "$BASE/_inbox" "$BASE/_raw"`를 실행한다 — 1차 스캐폴드에 이 두 폴더가 아직 없어, 없으면 `cp -n`이 조용히 실패해 결과 JSON이 회수되지 않는다(README의 스캐폴드 규격 복원일 뿐 새 구조가 아니다).
이유: 이 컴퓨터에서 푼 결과 JSON은 이 컴퓨터의 Downloads에만 있다. 이 단계가 velog-posts 원장으로 회수하는 유일한 경로다.
§3(오답 재도전 퀴즈)은 하지 않는다 — odap-quiz-bupsa 몫. 원천 0건(exit 2)·원장 미가동은 초기 트랙(특히 1차)에서 정상 — 보고만 하고 (b)로 진행한다.
**(b) 데일리 생성** — 베이스_데일리퀴즈 §0~§6(§5.5 포함)을 프로파일 값으로 그대로 실행. §5.5 저장 전 `mkdir -p "$QD/_push"`(1차엔 아직 없다). 램프업 단계 판정(스킵/유지/S0~S3)·문항 수·미니답안 편성은 프로파일 표가 기계적으로 정한다 — 임의 조정 금지.

## 4. 온디맨드 특칙

- 요일 무관 실행(화·목 제한은 맥 cron 설정일 뿐). "오늘 하루치 1개만" 가드는 그대로 — 과거 날짜분 생성 금지.
- 해당 트랙의 오늘분 html이 이미 있으면 새로 만들지 말고 **그 파일을 present_files로 제시**한다(사용자는 지금 풀 문제지를 원한다). (a) 수거·원장 갱신은 그래도 수행.
- 맥 스케줄러가 도는 화·목 오전(08:50~09:20 즈음)과 겹치면 이중 생성·동기화 충돌 위험 — 그 시간대면 잠시 뒤 실행을 권한다.
- 마무리 안내 1줄: 풀고 저장한 결과 JSON(Downloads)은 다음 퀴즈 스킬 실행 때 자동으로 원장에 회수된다.
