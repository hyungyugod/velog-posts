## 데일리퀴즈 (베이스_데일리퀴즈용)

- **신규 원천 규칙**: `$ROOT/법무사` 최상위(-maxdepth 1)의 `20*.md` 중 **파일명 날짜**(mtime 아님)가 오늘−7일 이후인 것 전부. README·설계서·보고서 등 날짜 프리픽스 없는 파일은 원천이 아니다. 0바이트 파일은 건너뛰고 보고에 명시. **차수 판별: 파일명에 `-2차-` 포함 → exam="2차" → 그 노트의 모든 문항은 단답형.** 그 외 exam="1차" → 객관식. 정리본의 `📐 공식` 블록·판별식·⚠ 예외가 최우선 소재.
- **출제 필터 (개정법)**: `ai-guidelines/20_프롬프트-라이브러리/19_법무사_개정법워치_v1.md` §2 표를 실행 시 직접 읽는다(복제 금지 — 드리프트 방지). **단, 스케줄 세션에 ai-guidelines가 마운트되지 않았으면 필터 파일을 건너뛰되 다음 최소 규칙은 항상 적용**: 형사소송법 수사·기소 분리(2026.10 시행) 시행 전까지 형소 수사 파트 출제 제외, 개정 영향 소재는 해설에 `⚠ 개정 반영` 표기, 구법 확정 소재 출제 금지. 필터 파일을 못 읽었음을 보고에 명시.
- **구성 모델 (램프업형)** — 기계적 판정(위에서부터 첫 일치). `신규`=원천 노트 수, `장기`=장기복습 후보 수, `한달전창`=창의 파일 수:

| 단계 | 조건 | 총 문항 | 구성 |
|---|---|---|---|
| 스킵 | 신규 0 · 장기 0 | 0 | 생성하지 않고 "원천 없음" 1줄 보고 후 종료 |
| **유지** | 신규 0 (9/21~10/31 중개사 올인 구간) | 장기 ≥3이면 **20**, 아니면 **15** | 전부 장기복습(⏪) |
| S3 완전체 | 한달전창 ≥1 ∧ 장기 ≥3 | **50** | 본편 40(신규 30+장기 10) + 한달전 10 |
| S2 | 장기 ≥3 | **40** | 신규 30 + 장기복습 10 |
| S1 | 신규 ≥3 | **30** | 전부 신규 |
| S0-2 | 신규 = 2 | **20** | 전부 신규 |
| S0-1 | 신규 = 1 | **15** | 전부 신규 |

  단계·총 문항을 보고 첫머리에 명시. 어떤 단계에서도 노트에 없는 내용으로 문항 수를 맞추지 않는다 — 모자라면 줄이고 사유 보고.
- **한달전 폴백**: 없음 — 창이 비면 한달전 블록을 편성하지 않는다(초기엔 파일이 적은 게 정상).
- **추가 토큰**: `{{ALERT_HTML}}` → 아래 '미제출 경보' 규칙의 경보 문구, 경보 없으면 **빈 문자열**.
- **템플릿 토큰 문구**: `{{META_LINE}}` = "2026년 M월 D일 (요일) · {단계명} {N}문항 (단답 a · 객관식 b) · 장기복습 N(⏪) · 한달전 N(🔄)" / `{{TAGS_HTML}}` = `<span class="tag">⚖️ 법무사</span><span class="tag">✍️ 2차 단답 N</span><span class="tag">📝 1차 객관식 N</span>` + 장기복습·한달전 태그(해당 시) + 오늘 과목명 태그들. *(재도전 태그·재도전 N(🔁) 표기는 v1.1에서 제거됨.)*
- **과목 배분**: 발견 과목 수로 균등(차이 ≤1). *(11/1 이식 시 문항수 비례 가중으로 교체 예정 — 아래 체크리스트.)*
- **유형 쿼터**:
  - 1차(객관식, 1차 문항 수 n에 비례): 판례결론형 30% / 일반 35% / 조합 17.5% / OX 12.5% / 사례 5% (나머지는 판례→일반 순). 판례결론형 해설엔 **결론을 가른 사실관계 변수 1개** 필수. 부정형 30~50%. **계산형 금지**(수치 VOLATILE — 산식·판단 순서만 소재로).
  - 2차(단답, 소유형 가이드 — 엄격 쿼터 아님·편중 금지): 요건·개수형 ~25% / 판별식형 ~25% / 목차·순서형 ~15% / 판례결론·문구형 ~15%(노트에 판례 문구 있을 때만) / 사례단답형 ~10% / 용어·정의형 ~10%. "~란 무엇인가?" 단순 정의는 전체 15% 이하.
- **문항 특칙**:
  - 단답형(2차 전용): 추가 필드 `answer`(모범답 1~2문장 핵심) + `keywords`(자가채점 키워드 2~4개 배열), `opts` 없음. 발문은 인출 지향("3요소를 순서대로 쓰라"/"둘을 가르는 단일 변수를 쓰라"/"빈칸"/"결론과 근거 한 줄"). 보기 힌트를 발문에 흘리지 않는다.
  - 근거 표기: 조문은 노트에 명시된 것만. 불확실한 조문·판례·예규 번호는 지어내지 말고 번호 없이 내용으로. "(원문 확인 필요)"류 태그를 남기지 않는다(태그가 필요한 소재는 버린다).
- **추가 안티패턴**: 구법 소재 / 확인-필요 태그 잔존.

- `mkdir -p "$QD/_push"` 후 `$QD/_push/{오늘날짜}.json` 생성:

- `counts.재도전`은 **항상 0**(v1.1 — 키는 스키마 호환용으로만 유지, 임의 삭제 금지).
