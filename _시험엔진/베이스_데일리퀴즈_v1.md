## 0. 경로·중복 가드 (가장 먼저)
- 항상 **'오늘 하루치 1개'만** 만든다. 밀린 과거 날짜분 생성 금지.
- bash `date +%F`로 오늘 날짜. 마운트는 늦게 붙는다 — 첫 조회가 비어도 부재로 단정 금지(2026-07-27 사고):
```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break; echo "velog-posts 대기... ($i/5)"; sleep 5
done
```
- 5회 후에도 비면 파일 도구로 `~/Desktop/velog-posts` 직접 확인, 둘 다 실패 시 "velog-posts 접근 불가" 보고 후 종료(엉뚱한 곳 생성 금지).
- `QD=$ROOT/⟨프로파일: EXAM_DIR⟩/데일리퀴즈`. `$QD/{오늘날짜}.html` 존재 시 → "오늘 문제지는 이미 생성되어 있다"만 알리고 즉시 종료. 템플릿 `$QD/_template.html` 부재 시 → 생성하지 말고 "템플릿 부재" 보고 후 종료. 괄호 포함 파일명은 bash `cat`으로 읽는다.

## 1. 자료 수집
### 1-1. 신규 원천 (최근 학습 노트)
- 후보 선정: `⟨프로파일: 신규 원천 규칙⟩` (폴더·날짜 기준·제외 규칙·차수 판별 등).
- 발견된 모든 노트를 **처음부터 끝까지 전부 정독**(발췌·건너뛰기 금지). 핵심 개념·규정·숫자·함정·암기코드 파악.
- ⚠️ 노트의 "확인 필요/⚠️" 섹션·표에 오른 수치·항목은 **출제 절대 금지** (검출 키: 정규식 `⚠️?|확인 ?필요` — VS16 없는 ⚠·띄어쓰기 변형 포함, v1.3).
- 신규 노트 0개여도 종료하지 않는다 → §2의 구성 판정이 처리한다(전일/유지 모드).
- `⟨프로파일: 출제 필터⟩`가 있으면 적용(개정법 필터 등).
### 1-2. 과거 출제 회피
- `grep -ho 'q: *"[^"]*"' "$QD"/20*.html | sort -u`로 과거 문제문 전부 추출·정독(파일 없으면 생략).
- 오늘 본편 문항은 **같은 개념 + 같은 각도** 반복 금지 — 다른 조문·다른 숫자·다른 각도(긍정↔부정, 정의↔사례, 방향 뒤집기)로. 예외 1가지: §1-4 한달전 복원(원문 그대로가 목적).
### 1-3. 장기복습 원천 = 옛 노트 로테이션 (⏪)
- 후보: `⟨프로파일: 장기복습 원천 규칙⟩` — 일반형은 "EXAM_DIR 최상위 `20*.md` 중 **파일명 날짜** ≤ 오늘−7일(mtime 아님)". 트랙 분할 시험(예: 법무사 1차/2차)은 공유 노트 폴더 + 차수 필터를 프로파일이 정의한다.
- 로그: `$QD/_장기복습_로그.json` — `{"파일명.md": {"last":"YYYY-MM-DD","n":횟수}}`, 없으면 빈 객체.
- 버킷: **B1 7~44일** 3문 · **B2 45~89일** 3문 · **B3 90일+** 4문 = 기본 10문 고정 (경계일 소속 확정 — v1.3). 후보 없는 버킷 몫은 더 오래된 버킷으로 이월. (전일 모드 등 총량 변화는 `⟨프로파일: 구성 모델⟩`이 정한다.)
- 노트 선정: 버킷마다 ① 미서빙 노트 우선, 파일명 오래된 순 ② 전부 서빙됐으면 `last` 오래된 순 — 기본 1~2개(확대 모드는 3~4개). 선정 노트는 전문 정독 후 그 노트에서만 출제.
- 표기: 문제문 맨 앞 `⏪ `, src 끝 `(장기복습·N일전)`. §1-1 확인필요 금지·§1-2 회피 그대로 적용.
- 생성 완료 후 로그 갱신(`last=오늘, n+=1`).
### 1-4. 한달전 복원 = 30일 전 출제분 그대로 (🔄)
- 창: `$QD/20*.html` 중 파일명 날짜 오늘−33 ~ 오늘−27. 창이 비면 `⟨프로파일: 한달전 폴백⟩`을 따른다.
- 선정(기계적): ① 후보의 QUESTIONS에서 `retryOf`·`monthlyOf` 문항 제외(순수 출제분만 — 과거 파일엔 🔁이 남아 있다) ② 과목(cat)별 최대 3문으로 골고루 10문, 같은 과목 안에선 type 안 겹치게 ③ 문항 필드 전부 **원문 복사**(q 맨 앞 🔁/⏪ 제거 후 `🔄 ` 부착, src 끝 ` (한달전 재출제·원본 YYYY-MM-DD)` 부착, 단답형이면 answer·keywords 포함 그대로) ④ `monthlyOf:"YYYY-MM-DD"` 추가.
- 배치: QUESTIONS 배열 **맨 뒤** 별도 블록(블록 안 같은 과목 연속).

## 2. 구성 판정 + 출제 계획표 (문항 작성 전 필수 — 건너뛰기 금지)
- **총 문항·소스 구성은 `⟨프로파일: 구성 모델⟩`이 정한다** (고정형/램프업형·전일/유지 모드 포함). 판정 결과(모드·총 문항)를 보고 첫머리에 명시.
- 전 문항 계획표: `# | 소스(신규/장기/한달전) | 과목 | 출처 소제목 | conceptKey | 개념+함정 설계(한달전은 "원문 복사") | type | 정답idx(객관식만) | 표기`.
- 과목 배분: `⟨프로파일: 과목 배분⟩` (기본: 발견 과목 수로 고르게, 차이 ≤1). QUESTIONS 배열에서 **같은 과목 연속 배치**(한달전 블록은 맨 뒤 자체 정렬).
- 유형 쿼터: `⟨프로파일: 유형 쿼터⟩`.
- **정답-해설 정합 (v1.4, 2026-09-01 실사고)**: 정답 사전 배정(분산 맞추기) 때문에 **내용상 정답 보기와 `answer` 인덱스가 어긋나는 사고**가 실제 발생했다(부정형 발문에서 answer가 참 지문을 가리키고 해설은 다른 보기를 설명 — 당일 데일리 1번). 문항마다 해설을 쓴 직후 `opts[answer]`를 다시 읽고 **"[정답 근거]가 설명하는 보기가 바로 이 보기인가"를 자문**한다. 검증 스크립트의 정합 휴리스틱(해설 첫 문장↔보기 2-gram 대조)에 걸리면: answer 오배정이면 answer를 고치고, 오탐이면 [정답 근거] 첫 문장을 정답 보기를 직접 서술하도록 다시 쓴다 — 어느 쪽이든 결과물이 좋아진다.
- 정답 사전 배정(객관식만): 0~3 균등(차이 ≤1) 배정, 같은 인덱스 3연속 금지, 보기를 쓸 때 처음부터 그 위치에 정답 배치. OX는 O·X 균형(차이 ≤1). 한달전 문항은 원본 answer 그대로(재배정 금지) — 전체 배열에서 3연속이 생기면 한달전 블록 내부 순서만 교체.

## 3. 문항 작성 규칙 (공통)
- 발문: 실제 시험 형식. 보기: 내용만(번호 금지), **오답 보기는 정답과 '한 끗 차이'**(숫자 스왑·주체 교체·기간 교체·원칙↔예외·유사 제도 교차), 더미 금지, 정답 보기 길이 티 안 나게.
- 해설(expl): `[정답 근거] → [메커니즘 1문장] → [함정·비교 1문장]` 3문장 250자 이내.
- src: `YYYY-MM-DD 과목 소제목` — 실제 읽은 노트의 것만. 문자열에 큰따옴표(")·백틱 금지(따옴표는 ').
- 필드 계약 공통: `{type, cat, q, opts, answer, expl, src, conceptKey}` + 한달전이면 `monthlyOf`. **retryOf 금지.** conceptKey = `과목 소제목-요지` 짧게(한달전은 원본 그대로). 추가 필드·유형별 특칙은 `⟨프로파일: 문항 특칙⟩` (단답형 계약·계산형 calc 검산·판례결론형 등).
- 안티패턴 금지: 노트에 없는 내용 / 확인필요 수치 / 과거 문제문 재사용(한달전 제외) / 쿼터 임의 축소 / 한달전 임의 변형 / 오답 원장 참조 출제 / `⟨프로파일: 추가 안티패턴⟩`.
