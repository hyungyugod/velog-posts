# 주간리포트 절차 (매주 월요일, 전 시험 공통)

> 역할: ① 안전망 수거 ② 주간 오답노트(원장 뷰) ③ 무음실패 백신(결과 도착·실행 로그 대조) ④ Phase 2 관찰 지표(표식·커버리지). 평일 수거·재도전 퀴즈는 오답 파이프라인 몫 — 여기서 퀴즈를 만들지 않는다.
> **저장 위치 불변**: 노트·원장·`_inbox`의 정본은 `<velog-posts>/<시험폴더>/claude_ox_오답/`. Downloads는 원천일 뿐 저장소가 아니다.

## 1. prepare — 사실 수집

```bash
python3 "$E/prepare_quiz.py" --exam <gongin|bupsa1|bupsa2> --kind weekly
```
→ `<시험폴더>/claude_ox_오답/_work/<date>.weekly.plan.json`: 원장 통계(제출·평균·누적 오답·상태·과목 약점·듀 큐 상위 8) · 지난 7일 데일리/오답 문제지별 결과 도착표(**`-RQ`는 데일리 신호가 아니다**) + 미수거 3건 이상 경보 · 지난주 오답(2회+ 표시)·졸업·졸업후보·상습 목록 · **표식 지표**(이번 주 노트별 ★★/★/n: 줄 수) · **실행 로그 요약**(`_runs.log` — 스케줄 대비 미실행일). `exists`면 종료. 원장 exit 2면 "원장 초기 — 원천 0건" 보고 후 종료.

## 2. AI — 노트 작성 (원천 = plan의 사실만, 추가·추정 금지)

저장 `<시험폴더>/claude_ox_오답/<date>-claude_oxquize.md`. 순서:
① 제목 + 인용블록(기간·제출·평균·지난주 오답 수) ② `## 🟦 과목명` 지난주 오답 상세(문제/정답/해설/함정 키워드 — 원장 samples 그대로, 2회+는 `🔁 N회` 맨 위) ③ `## 🎓 졸업·졸업후보` ④ `## 🔴 상습 경보` 표 ⑤ `## 🗓️ 다음 주 복습 큐` 듀 상위 8 표(R·놓친 포인트·원인 포함) ⑥ `## 📊 패턴 분석` 5분류(숫자 함정/의심병/주체·권한 혼동/단정 표현/비슷한 이름 쌍) + 최대 적신호 1개 ⑦ `## 🔑 핵심 암기카드 5장`(⚠️·확인 필요 제외) ⑧ `## 💡 콘텐츠 소재 후보 3`(질문형 훅 1줄) ⑨ `## ✅ 기대치 검증`(결과 도착표·미수거 경보·**실행 로그 미실행일**·**표식 지표** — 노트당 ★ 평균, 4주 연속 <3이면 "표식 파이프라인 축소 검토" 1줄).
- 지난주 오답 0(만점 또는 데이터 공백 — 구분 명시)이면 ②⑥⑦ 생략. 원장 초기 시험은 있는 만큼만 + "원장 초기 — N주 후 완전체".
- `_runs.log`에 `ISO시각\t<exam>\tweekly\tOK\t<노트 파일명>` 1줄 append.
