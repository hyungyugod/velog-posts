# 참조_법무사1차_기출문형 v1 — 객관식 기출 구조 실측 (2026-08-28)

> **용도**: 법무사 1차 트랙의 데일리퀴즈·오답퀴즈 실행자가 실제 기출 구조 그대로 출제하기 위한 형식 정본. `spec/프로파일_법무사1차.md`가 실행 시 필독을 지시한다.
> **근거**: 제29~31회(2023~2025) 1차 기출 **8과목 × 3개년 = 600문항 전수 기계 집계** (2026-08-28 분석 — 법원 공식 시험자료실 공개 원문의 재현본 기준). 최신 기출은 제31회. **제32회(2026-08-29 시행) 입수 후 이 파일을 갱신한다.**
> **절대 규칙**: 이 파일은 형식만 제공한다. 문항 내용 소재는 원천 노트에 있는 것만(환각 문항 금지). 기출 지문 원문을 복제하지 않는다 — 구조만 빌린다.

## §1. 발문 — 상투구가 전부다

### 1-1. 발문 어미 화이트리스트 (이 밖의 발문 금지)

| 유형 | 정확한 문구 | 기출 비중 |
|---|---|---|
| 표준 부정형 | "[주제어]에 관한 다음 설명 중 **가장 옳지 않은 것은?**" | **75~85% (최빈)** — "가장"을 빼지 않는다 |
| 표준 긍정형 | "…중 **가장 옳은 것은?**" | 8~12% |
| 조합 부정형 | "…중 옳지 않은 것을 **모두 고른 것은?**" ("가장" 없음) | 조합형의 절반 |
| 조합 긍정형 | "…중 옳은 것을 **모두 고른 것은?**" | 조합형의 절반 |
| 개수형 | "다음 중 ○○는 **모두 몇 개인가?**" | 회당 1~2문 |
| 열거 선별형 | "…에 **해당하지 않는 것은?**" / "…이 **아닌 것은?**" / "…이 **다른 하나는?**" / "…끼리 **고른 것은?**/**연결된 것은?**" | 회당 3~7문 (등기·가족법 집중) |
| 조문 빈칸형 | "다음은 ○○법 제○조이다. 괄호 안에 **들어갈 내용으로 옳은 것은?**" | 가족법 회당 0~3문 |

- 주제어 선행 구조 절대적: "[2~15자 법률 개념어]에 관한 다음 설명 중 …".
- **밑줄형 발문·`<보기>` 박스: 3개년 600문항에서 0건 — 만들지 않는다.**
- 부정형 비율 실측 85.0% (3개년 평균) → 퀴즈 목표 **65~90%**.

### 1-2. 지시문 — 과목 블록 첫 문항에 1회만 (매 문항 반복은 기출과 다름)

퀴즈에서는 **과목 블록의 첫 문항 발문 끝**에 해당 과목 지시문을 1회 부착한다:

| 과목 | 지시문 (제31회 원문) |
|---|---|
| 헌법 | [다툼이 있는 경우 대법원 판례(전원합의체 판결의 경우 다수의견에 의함) 및 헌법재판소 결정에 의함] |
| 민법 | (다툼이 있는 경우 판례에 따르고 전원합의체 판결의 경우 다수의견에 의함) |
| 상법 | (다툼이 있는 경우 대법원 판례에 따르고 전원합의체 판결의 경우 다수의견에 의함. 특별한 언급이 없다면 각 지문의 회사는 자본금 총액이 10억 원 이상인 비상장 주식회사를 의미함) |
| 민사집행법 | (다툼이 있는 경우 판례⋅예규에 따르고 전원합의체 판결의 경우 다수의견에 의함) |
| 부동산등기법·공탁법·상업등기비송·가족관계등록법 | (다툼이 있는 경우 판례⋅예규 및 선례에 따르고 전원합의체 판결의 경우 다수의견에 의함) |

## §2. 유형 규격 — 전 문항 5지선다 (opts 5개·answer 0~4)

| type | 규격 | 편성 가이드 |
|---|---|---|
| 일반 | 지문 5개 단순 5지 (선별형·조문형 포함) | ~40% |
| 판례 | 판례 결론 평서화 지문 5개 — **해설에 결론을 가른 사실관계 변수 1개 필수** | ~30% |
| 사례 | 발문은 표준형 유지, **선지 안에 甲乙丙 사실관계 압축** (별도 사례 박스 발문은 기출에 없음) | ~15% |
| 조합 | 지문 4~6개(ㄱ~ㅂ, 변형 ㉠·가.·A. 허용)를 발문에 `<br>ㄱ. …` 로 나열, 선지는 **3개 조합 5쌍** (예: ① ㄱ, ㄷ, ㄹ ② ㄱ, ㄷ, ㅁ …) | ~10% (민법·상법·공탁·가족에 편중, 헌법·민집·상등은 기출 0건) |
| 개수 | 지문 5~6개면 선지 "1개~5개", 4개면 "없음·1개~4개" | **세트당 0~1문, 부동산등기법·가족관계등록법 소재일 때만** (타 과목 기출 0건) |

- **OX 없음** — 기출 미출제 유형. 계산형·단답형도 금지(수치는 VOLATILE — 산식·판단 순서만).
- 정답 사전 배정은 **0~4 균등**(차이 ≤3)·같은 인덱스 3연속 금지 (베이스의 "0~3"은 4지용 — 이 트랙이 대체).
- 템플릿 보기 라벨은 A~E 자동 부여 — **opts 문자열에 ①②③ 번호를 넣지 않는다**(중복 표기).
- 동일 주제를 한 세트에서 다른 각도로 2문 배치하는 것 허용(기출 실태 — 31회 민법 상계 2문).

## §3. 지문(선지) 문체

**P1 판례 평서화 (지배적)** — 판결번호·"판례에 따르면"·"판시하였다"를 지문에 절대 쓰지 않는다. 골격: "[요건사실]…한 경우, [주체]는 [상대방]에 대하여 ~을 주장할 수 있다/없다."
**P2 조문 번호 인용** — "민법 제443조의 담보제공청구권은 …" 처럼 번호+제도명. 노트에 명시된 조문만.
**P3 조문 축약 복제** — 본문+단서를 한 지문에: "…을 청구할 수 있다. 그러나 [예외요건]인 경우에는 그러하지 아니하다."
**P4 사례 압축(등기·공탁·상법)** — "甲과 乙이 공유하는 X 토지에 [사건1]이 마쳐진 상태에서 [사건2]가 있은 경우, [당사자]는 ~을 단독으로 신청할 수 있다."
**P5 절차·요건 열거(등기·비송)** — 종결 동사는 신청·제공·말소·기록 계열: "~를 첨부정보로 제공하여야 한다."
**P6 헌법** — "헌법 제13조 제1항에서 금지하는 [개념]은 …일 뿐, …할 수 없는 것은 아니다." (헌재 결정 요지 평서화 + 조문번호 명시)

**지문 길이 타깃** (공백 제거 실측 중앙값 — 공인중개사의 3~4배가 이 시험 난도의 실체):

| 과목 | 타깃 | 상한 |
|---|---|---|
| 민법·상법 | 100~120자 | 200자 (세트당 1~2개만 350자까지 허용) |
| 민사집행법 | 90~100자 | 〃 |
| 헌법·부동산등기법 | 80~90자 | 〃 |
| 공탁법·상업등기비송 | 65~75자 | 〃 |
| 가족관계등록법 | 50~60자 | 〃 |

**근거 층위 배분**: 부동산등기법은 실측 **조문 20% : 예규 47% : 선례·판례 33%** — 지문 5개 중 2~3개를 예규·선례 근거로. 공탁법은 공탁규칙·행정예규 중심, 가족법은 조문 원문 비중 최고(빈칸형 존재), 민법은 판례 결론 위주.

## §4. 함정 설계 패턴 (오답 지문 제작 원천)

| # | 패턴 | 배분 가이드 |
|---|---|---|
| T1 | 결론 반전 — 문말 서술어만 교체 ("~할 수 있다↔없다", "해당한다↔하지 아니한다") | 30% |
| T5·T7 | 절차·기관 교체 — 단독↔공동신청·부기↔주등기·직권↔신청말소 / 집행법원↔수소법원·시읍면장↔가정법원 | 20% |
| T6 | 기간·수치·기준시점 교체 — 10년↔5년, 15세 이상↔미만, 본등기 시↔가등기 시 | 15% |
| T3 | 원칙·예외 교차 — "그러나/다만" 단서의 요건 한쪽만 교체 | 15% |
| T8 | 유사 제도 교차 — 추심↔전부명령, 가압류↔가처분, 채권자대위↔취소, 부속물↔건물매수청구 | 10% |
| T2 | 절대화어 삽입("언제나·반드시·항상·모든")으로 예외 삭제 — **세트당 3문 이내** (남발 시 '절대화어=오답' 메타 발생) | 10% |
| T10·T11 | 효력 발생시기 교차(송달 시↔등기 시) / 효력 범위 확장·축소("~에 미친다↔미치지 아니한다") | 보조 |
| T9 | 상법 전용 — 지시문의 "자본금 10억 비상장" 전제로 소규모·상장회사 특례를 역으로 묻기 | 상법에서만 |

## §5. 과목별 한 줄 특성

민법(40문): 판례 평서화 지문·조합형 매년 4~5문·지문 최장. / 헌법(20문): 순수 5지 단일 유형(조합·개수·사례 3개년 0건)·헌재 결정+조문번호. / 상법(30문): 부정형 편중 최심·지시문 전제 함정·조합 지문 최장(200자+). / 민사집행법(35문): "가장 옳지 않은 것은?" 단일 발문으로 거의 전부·절차·시기 교체 함정·과락률 최고. / 부동산등기법(30문): 예규 지문 47%·甲乙 등기 시계열 사례 회당 6~9문·개수형·등기기록례 자료형 유일 출제 과목. / 공탁법(20문): 공탁규칙·행정예규 중심·지문 짧음·조합형 변동성. / 가족관계등록법(10문): 조문 빈칸형·개수형·선별형 집중, 유형 최다양·지문 최단·긍정형 비율 최고권. / 상업등기비송(15문): 열거 판별형·긍정형 비율 최고·조합·개수 0건.

## §6. 난도·시간 — 왜 공인중개사보다 어려운가

문항당 72초는 중개사와 같지만 **읽을 글자 수가 3~4배**(민법 중앙값 97~120자 vs 중개사 29자), 부정형 85%에 "가장"이라는 상대 판단 어사가 붙어 '명백한 오답'이 아니라 '가장 덜 맞는 것'을 고르게 한다. 합격선 64.5점(31회)·과락률 과목별 46~57%. → 퀴즈는 **지문 길이 타깃을 지키는 것**이 난도 재현의 핵심이다 — 짧고 쉬운 지문 50문은 기출 감각을 오히려 훼손한다.
