# 오답 파이프라인 절차 (수거 → 원장 → 재도전 퀴즈, 전 시험 공통)

> 실행 = `prepare → (AI) questions.json → render`. 법무사 2차는 **수·금·토·일 복습퀴즈**(≤12문, 화·목 데일리와 같은 날 안 겹침). 오답 데이터는 결과 JSON·원장에 있는 것만 쓴다(지어내기 금지). 이 시험의 파일만 이 시험의 폴더로 — 시험·트랙 간 교차 절대 금지.

## 0. 경로

`spec/데일리퀴즈.md` §0과 동일(5회 재시도, `E="$ROOT/_시험엔진/engine"`).

## 1. prepare — 수거·원장·듀 큐 플랜

```bash
python3 "$E/prepare_quiz.py" --exam <gongin|bupsa1|bupsa2> --kind retry
```
- Downloads → `_inbox` 수거(`cp -n`, `-RQ` 결과·브라우저 사본 `(1)` 포함, Downloads 불변) → `build_ledger.py --ingest` → (gongin) 대시보드 → 원장 `dueQueue`에서 **상위 N = min(상한, 듀 수)** (원장이 이미 상습 우선·망각위험순으로 정렬하고 졸업후보 예약칸까지 반영해 `pick` 표시 — 재정렬 금지) → 단답 승격 대상 표시 → `<시험폴더>/오답퀴즈/_work/<date>.plan.json`.
- `status`: `ready` / `exists`(오늘 것 있음 → 그 파일 제시, 덮어쓰기 금지) / `due0`(**듀 0 = 오늘 미생성이 정답** — 다른 원천을 끌어오지 않는다, "듀 0 — 오답퀴즈 없음" 1줄 보고).
- 원장 exit 2(원천 0건)는 초기 트랙(법무사 1차)에서 정상 — 그대로 보고하고 종료.

## 2. AI — 재도전 문항 작성

plan `picks`(conceptKey·samples·missedTop·causeTop·promote_sa·related_notes)로 `spec/문항작성.md` §2 규칙대로 `_work/<date>.questions.json` — 문항 수 = plan `n`, conceptKey는 pick 값 그대로.

## 3. render

```bash
python3 "$E/render_quiz.py" --exam <exam> --kind retry
```
🔁·retryOf·src `(재도전)` 부착, 정답 배정, 검증(재도전 표기·conceptKey∈듀큐·승격 조건·missedTop 반영·유형 계약·조합 편향·정합) → `<시험폴더>/오답퀴즈/<date>.html` + `_runs.log`. FAIL이면 questions.json만 고쳐 재실행.

## 4. 결과 루프 (안내)

풀고 저장한 `*_오답_<date>-RQ.json`이 다음 실행 §1에서 자동 수거되어 졸업(연속 정답 3)·상습(재도전 실패)·FSRS 간격에 반영된다. 돌아오지 않으면 듀 큐가 줄지 않는다. 카톡 푸시는 데일리 전용(kakao_push.py 수정 금지).
