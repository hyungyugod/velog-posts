# 프로파일 — 법무사 1차 (객관식 트랙, 특칙만)

> 정본 수치는 `engine/exams.json` → `exams.bupsa1`. **필독 참조**: `spec/참조_법무사1차_기출문형.md`(발문·지문·함정 정본). 개정법 필터: `ai-guidelines/20_프롬프트-라이브러리/19_법무사_개정법워치_v1.md` §2 — 미마운트 시 최소 폴백(형소 수사·기소 분리 2026.10 시행 전 형소 수사 파트 제외, 개정 영향 소재는 해설에 `⚠ 개정 반영`, 구법 확정 소재 금지, 못 읽었음을 보고).
> 트랙: 노트는 `법무사/` 최상위를 2차와 공유, **파일명에 `-2차-`가 없는** 날짜 정리본만 이 트랙. 산출·원장·결과는 `법무사/1차/`. 현재 1차 노트 0 — 스킵 보고가 정상, 노트가 생기면 자동 램프업.

## 작성 특칙 (기출 실전형 — 기출문형 참조 필독)

- **발문**: 기본형 "[주제어]에 관한 다음 설명 중 가장 옳지 않은 것은?" — 화이트리스트 밖 발문 금지, "가장" 누락 금지, 부정형 65~90%. 과목 블록 첫 문항 끝에 과목 지시문 1회(§1-2). 밑줄형·보기 박스 금지.
- **지문**: 판례는 판결번호·"판례에 따르면" 없이 결론 평서화(P1), 조문은 번호+제도명(노트 명시분만), 부등법은 지문 5개 중 2~3개를 예규·선례 근거로. **길이 타깃 준수**(민·상 100~120자 등, 상한 200 — 세트당 1~2개만 350) — 짧고 쉬운 지문은 기출 감각을 훼손.
- **유형 가이드**: 일반 ~40% · 판례결론형 ~30%(해설에 **결론을 가른 사실관계 변수 1개** 필수 — "변수/가른/기준" 검사) · 사례 ~15%(선지 안에 甲乙 압축) · 조합 ~10%(지문 4~6개, 참 항목 **정확히 3개**, 헌법·민집·상등 소재 금지) · 개수형 세트당 0~1(부등·가족 소재만).
- **오답 지문 = 함정 패턴표**(§4): T1 결론반전 30% / T5·T7 절차·기관 교체 20% / T6 기간·수치 15% / T3 원칙·예외 15% / T8 유사제도 10% / T2 절대화어 10%(세트당 3문 이내).
- 근거 표기: 조문은 노트 명시분만, 불확실하면 번호 없이 내용으로. "(원문 확인 필요)"류 태그 잔존 금지.
- ★ 가중·백지복습 원천 규칙은 중개사 프로파일과 동일(트랙 판별: 백지복습 보고서는 파일명 `-2차-` → front matter `exam:` → 둘 다 없으면 제외·보고).

## 오답퀴즈

5지 기본 + 단답 승격(최대 5, 조건 상습∨재도전실패≥1∨틀림≥3). 변형 각도는 함정 패턴표 우선, missedTop·causeTop 규칙은 `spec/문항작성.md` §2.
