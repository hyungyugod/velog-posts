# 주간 Anki 원자카드 덱 + 숫자 총정리 갱신 (매주 월요일, 시험 횡단)

> v1.1 (2026-09-03): 레인 상한 정본화(exams.json _anki, 25→60)·이월/n: 원천·독립 검증 게이트·국면 2 연동

> **원자층 전용** — 3초 안에 답하는 사실(숫자·기간·비율·요건 개수·두문자·판례결론 1줄)만 카드화. 문항형·서술형 카드 금지(적용층 퀴즈와 이중 복습 — `공부루틴_OS_v1.md` §3 경계 규칙). 프로파일 없이 단독 실행. 산출 `_시험엔진/anki/`.

**실행 원칙** ① 원문(원장 samples·정리본·백지복습 보고서)에 없는 내용 카드화 절대 금지 — 틀린 카드는 틀린 기억을 영구 각인 ② "(확인 필요)"·⚠️ 항목 금지 — 단 법령 원문 대조로 '확정 완료'된 총정리본 충돌 항목은 확정값으로 카드화 가능(오기였던 쪽은 뒷면에 함정 백신) ③ 원문에 없는 조문번호·수치는 카드에서 뺀다 ④ **강조 표식 두 등급** — `★★`/`!!`(기출 직결)만 전량 의무 편입·상한 제외, `★`/`!`(강사 강조)는 경쟁 레인 상한(**정본 `engine/exams.json` `_anki.weekly.lane_cap_notes` — 현재 60노트**) 안에서 경쟁. 절단 우선순위 상습 > 백지 구멍 > ★ > n:, 같은 레인 안에서는 이월 → 시험일 가까운 순 → 노트 날짜 순. 잘린 항목은 검수리포트 이월 표에 남겨 다음 주 최상단. 유효 표식은 **줄머리에 붙은 것만**. ②가 ④에 우선 ⑤ **표식 없는 항목을 강조 레인에 넣지 않는다** — 강조 카드는 검수리포트에 표식이 붙은 원문 줄을 그대로 인용해야 하고, 못 대면 레인 탈락 ⑥ 검증 통과 전 종료 금지 ⑦ **정규 덱 총 카드가 `_anki.weekly.independent_review_min_cards`(30) 초과면 별도 에이전트 전수 원문 대조 필수** — 결과(사실 오류 N·인출 설계 결함 N)를 검수리포트 머리에 기재.

## 0. 경로

`spec/데일리퀴즈.md` §0 재시도로 `ROOT` 확보, `AK=$ROOT/_시험엔진/anki`. `$AK/출고/<date>.apkg`가 이미 있으면 덱 생성(§1~5)만 건너뛰고 **§6은 수행**(다른 진입점이 없다).

`exams.json` `_anki`를 먼저 읽어 `lane_cap_notes`·`card_ceiling`·`final_phase`를 확정한다. 오늘이 `final_phase.gongin.from` 이후면 공인중개사 레인은 그 값으로, `exam_date − stop_from_days_before_exam` 이후면 공인중개사 카드 출고 0(법무사만).

## 1. 후보 수집 (활성 시험만 — `exams.json`에 `"status":"closed"`인 시험 제외)

| 원천 | 위치 | 규칙 |
|---|---|---|
| ① 상습 오답 | `<시험폴더>/claude_ox_오답/_ledger/오답_원장.json` `ledger[]` | `timesWrong>=2 or retryMissed>=1`(status 문자열로 거르지 말 것). samples(q·expl)가 유일한 근거. **원인 필터**: `errorCauses`가 실수뿐인 개념은 제외(검수 꼬리에 기재), `causeTop=혼동`이면 뒷면에 혼동 상대 1줄 필수(`causeNote` 1순위) |
| ②-A `★★`·`!!` | `<노트폴더>` 최상위 `20*.md` 중 **파일명 날짜가 오늘−7일 이내**(이번 주 정리본 — mtime 아님, 옛 노트 편집 부활 방지) | 줄머리 표식만 → 전량 의무 편입 |
| ②-B `★`·`!` | 〃 | 줄머리 표식만 → 레인 상한 안에서 경쟁(`_anki`) |
| ③ 백지 구멍 | `<노트폴더>/백지복습/*.md` **mtime −7일** | "남은 구멍"·"교정된 개념" 표의 나열형·숫자형만. `status: 닫힘` 제외 |
| ④ 이월 | `$AK/출고/검수_<직전 정규 덱 날짜>.md`의 「## 이월 (다음 주 우선)」 표 | 원문(원장·노트·백지 보고서)을 **다시 대조**한 뒤 편입, 원문이 사라졌으면 탈락 기재. 같은 항목이 2주 연속 이월이면 상습 앞으로 |
| ⑤ `n:` | ②와 같은 노트(파일명 날짜 −7일)의 줄머리 `n:` 라인 — §6-1 수집분과 동일 집합 | 출고 key에 없는 것만 — 최저 우선순위, `⚠️`/확인 필요 동반 시 제외(②와 동일 앵커 규칙, 대문자 `N:` 제외) |

- 노트폴더: `공인중개사` / `법무사`(1·2차 공유 — 파일명 `-2차-` 유무로 태그만 구분).
- ② 공통: 문장 중간 ★·백지시트 장식 무시. **표식 실측 카운트를 먼저** 낸다(노트별 `★★`/`★` 줄 수 → 보고·검수리포트). 전부 0이면 강조 레인 0장 + "이번 주 표식 0 — 줄머리 `!`/`!!` 습관 점검" 1줄.
- 중복 방지: `$AK/카드_*.tsv` 전체 key를 취합해 이미 출고된 key는 원문이 바뀐 경우만 재출고(같은 key = Anki에서 갱신).

**절단 절차**: 후보 총계를 낸 뒤 ★★를 전량 확정(상한 제외) → 나머지를 `_anki.weekly.lane_priority`(상습 > 백지구멍 > ★ > n:) + `tiebreak`(이월 → 시험일 가까운 순 → 노트 날짜 오름차순)로 정렬해 `lane_cap_notes`까지 채운다 → 넘친 나머지는 §4 꼬리 이월 표로. 빌드 후 총 카드가 `card_ceiling`을 넘으면 **자르지 말고** 검수리포트 머리에 "신규 N/일 기준 X일치" + "다음 주 lane_cap 권고값"을 표기한다(빌더도 같은 내용을 경고로 낸다).

## 2. 카드 문안 (원자화)

cloze 우선(`도시개발조합 설립인가 동의: 토지면적 {{c1::3분의 2}} 이상 + 총수 {{c2::2분의 1}} 이상`), basic은 "앞면 질문 1줄 → 뒷면 사실 1줄"이 자연스러운 것만. 앞면에 맥락 1줄 필수. 사실 2개면 카드 2장. 혼동 대상은 뒷면 1줄. key: 원장 항목은 `conceptKey` 그대로 / ★·백지 구멍은 `과목-소제목-요지`(한 conceptKey에서 여러 장이면 둘째부터 `-접미사`). deck `자격증::공인중개사::{과목}` / `자격증::법무사::{과목}`, tags 시험·과목·원천(상습/강조/백지/숫자/이월 — 이월은 원래 레인 태그에 `이월` 추가).

## 3. TSV → 빌드

`$AK/카드_<date>.tsv` (컬럼 `deck / type(basic|cloze) / front / back / tags / src / key`, 탭·줄바꿈 금지 — 줄바꿈은 `<br>`). `pip install genanki --break-system-packages` 후 `python3 "$ROOT/_시험엔진/engine/build_apkg.py" "$AK/카드_<date>.tsv"` → `$AK/출고/<date>.apkg`. 빌더가 카드 수·cloze 문법·key 중복·빈 값 검증(FAIL exit 1 → TSV 수정 재실행). **빌더 수정 금지**(모델 ID 2종 불가침). 특집 덱은 `카드_<date>-<주제>특집.tsv`(출력도 접미사 보존).

## 4. 검수리포트 `$AK/출고/검수_<date>.md` (생략 불가 게이트)

머리: 총 카드 수·시험/과목별·원천별(상습/★★/★/백지/n:/이월)·**표식 실측 표**·상한 집계(경쟁 레인 ≤ `lane_cap_notes`, ★★ 제외) + 총 카드/`card_ceiling` + 소화 일수(신규 N/일 기준 X일치) + 독립 검증 결과(사실 오류 N·인출 설계 결함 N). 본문: `# | deck | 앞면 | 뒷면 | 원천 | 표식 원문 줄 | src` — **표식 원문 줄은 ★★·★ 카드 필수**(못 대면 레인 탈락). 꼬리: 보류(확인 필요)·레인 탈락·실수 전용 제외, 그리고 상한 초과분은 제목을 정확히 `## 이월 (다음 주 우선)`으로 쓰고 열을 `원천 | 레인 | 항목 | 이월 횟수 | 사유`로 고정한다(다음 주 §1-④가 기계적으로 읽는다).

## 5. 전달

present_files: `.apkg` + 검수리포트. 3문장 + 고정 안내 "이번 덱 N장 = 신규 20/일 기준 X일치. 검수리포트 훑고 이상 없으면 .apkg 더블클릭 → Anki 임포트 → 동기화. 이상한 카드는 번호로 알려주면 다음 출고에서 수정." 카드 수정 요청 시 같은 key로 TSV 수정 → 재빌드.

## 6. 숫자 총정리 갱신 — `n:` 주간 시퀀스

1. 수집: 활성 시험 노트폴더 최상위 `20*.md` 중 파일명 날짜 −7일 이내에서 **줄머리 `n:`** 라인(문장 중간 제외, 대문자 `N:` 제외).
2. 정본: 공인중개사 → `공인중개사/공인중개사_날짜기간_총정리_v1.md` / 법무사 → `법무사/법무사_숫자체계_v1.md`(첫 `n:` 발견 시 같은 양식으로 생성, 그 전엔 스킵 보고).
3. 통합: 신규 항목만(항목명 대조) → 과목 표 `항목 | 기산일 | 기간·수치 | 혼동 주의` + 숫자 역인덱스 편입. 기존과 수치 충돌 시 본문에 넣지 말고 `⚠️ 충돌` 섹션에 나란히 + 보고. 원문에 없는 기산일 추정 금지(`—`).
4. 보고: 시험별 신규 N·충돌 N·역인덱스 최밀집 변동 1줄. `n:`은 §1-⑤로 경쟁 레인 최저 순위에 자동 편입(2026-09-03) — §6은 정본 통합만 담당.
5. `_시험엔진/_runs.log`에 `ISO시각\tanki\tweekly\tOK\t카드 N장·n: N건` 1줄.

## 7. 특집 덱 (온디맨드 — 사용자 요청 시에만)

`카드_<date>-<주제>특집.tsv` → `<date>-<주제>특집.apkg`. 검수리포트 동일 양식. 주간 레인 상한·`card_ceiling`과 별도(빌더 경고도 특집엔 적용 안 함). 실행 원칙 ①②③ 동일.
