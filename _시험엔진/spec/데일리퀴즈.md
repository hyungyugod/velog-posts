# 데일리퀴즈 절차 (전 시험 공통)

> 실행 = `prepare → (AI) questions.json → render`. 파라미터는 `engine/exams.json`, 시험별 특칙은 `spec/프로파일_*.md`, 문항 규칙은 `spec/문항작성.md`. 우선순위: 프로파일 > 문항작성 > 이 문서 > 위임문.

## 0. 경로 (마운트 지연 — 5회 재시도, 실패 시 생성 금지)

```bash
for i in 1 2 3 4 5; do ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1); [ -n "$ROOT" ] && break; sleep 5; done
[ -z "$ROOT" ] && { echo "velog-posts 접근 불가 — 종료"; exit 1; }
E="$ROOT/_시험엔진/engine"
```
파일 도구 경로는 `/Users/hg/Desktop/velog-posts/...`. 한글 경로는 bash `cat`이 확실하다.

## 1. prepare — 원천 선정·수거·플랜

```bash
python3 "$E/prepare_quiz.py" --exam <gongin|bupsa1|bupsa2> --kind daily
```
- 하는 일: Downloads 결과 JSON 수거(`cp -n`, Downloads 불변) → 원장 갱신(`build_ledger --ingest`, 대시보드) → 신규 원천(최근 7일 노트·백지복습 보고서) → 모드/단계·쿼터 판정 → 장기복습 노트 선정(미서빙 우선) → 한달전 블록(원문 복사) → 과거 문항 색인 → 미제출 경보 → `<시험폴더>/데일리퀴즈/_work/<date>.plan.json`.
- 출력 `status`: `ready`(진행) / `exists`(오늘 문제지 이미 있음 → 그 파일을 present_files로 제시하고 종료) / `skip`(램프업 스킵 — "원천 없음" 1줄 보고 종료). 밀린 과거 날짜분 생성 금지 — 항상 오늘 하루치 1개.
- Downloads 미마운트·원장 exit 2(원천 0건)는 보고만 하고 계속한다(데일리는 원장을 출제에 쓰지 않는다).

## 2. AI — 원천 정독 + questions.json 작성

plan의 `ai_brief`·`quotas`·`new_sources`·`longrev_picks`(노트별 `count`)·`past_questions`를 읽고, `spec/문항작성.md` 순서대로 `_work/<date>.questions.json`을 쓴다. 신규 `quotas.new` + 장기복습 `quotas.longrev`문(장기복습은 `source:"longrev"` + `note`). gongin은 `push_ox` 3문 포함.

## 3. render — 정답 배정·렌더·검증·부수 산출

```bash
python3 "$E/render_quiz.py" --exam <exam> --kind daily
```
- **evidence 대조**(단답 환각 게이트, `spec/문항작성.md` §1-4) → 정답 위치 균등 배정·3연속 회피·조합 셔플·⏪ 표기·과목 연속 배치·한달전 블록 병합·META/TAGS/ALERT 생성 → `validate_quiz.js` → 통과 시 `<시험폴더>/데일리퀴즈/<date>.html` + `_장기복습_로그.json` 갱신 + (gongin) `_push/<date>.json` + `_시험엔진/_runs.log` 1줄.
- 검사기는 **최근 7일 데일리와 신규 문항 conceptKey가 겹치면 FAIL**한다(`recent_concept_dup`). 백지복습 "남은 구멍" 재조준도 7일이 지나야 허용 — 걸리면 그 개념을 다른 개념으로 바꾼다.
- FAIL이면 `_work/<date>.draft.html`에 초안을 남기고 실패 항목을 출력한다 → **questions.json만 고쳐** 재실행. 통과 전 종료 금지, 기준 완화 금지, 템플릿·스크립트 수정 금지.

## 4. 보고

완성 `.html`을 present_files로. 2~3문장: 모드(단계)·총 문항·원천 노트 수·장기복습 노트(N일전)·한달전 원본 범위(또는 폴백)·단답 치환 수. 전부 한국어, 추천 질문 생략.
