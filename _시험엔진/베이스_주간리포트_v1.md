**[역할 분담]** 평일 수거·원장 갱신·오답 재도전 퀴즈는 해당 시험의 오답 파이프라인(평일)이 담당한다. 이 월요일 잡은 ① 안전망 수거 ② 주간 리포트(오답노트) 생성 전담. 데일리퀴즈는 재도전(🔁)을 싣지 않는다 — 듀 큐 소화는 오답 재도전 퀴즈 몫.

**[실행 원칙]** 오답 데이터는 결과 JSON에 있는 것만 쓴다(지어내기 금지). 집계는 build_ledger.py가 한다. 접근이 안 되면 추측하지 말고 그대로 보고.

**[저장 위치 불변 규칙 — 최우선]** 오답노트·원장·`_inbox`·`_raw`·`_processed.txt`의 정본은 오직 `<velog-posts>/⟨프로파일: EXAM_DIR⟩/claude_ox_오답/`. **Downloads는 원천일 뿐 저장소가 아니다** — 어떤 상황에서도 노트를 Downloads에 쓰지 않는다. velog-posts 접근 불가 시 노트를 만들지 말고 보고 후 종료.

## 0. 경로 (마운트 지연 대비 재시도)
- 베이스_데일리퀴즈 §0과 동일한 5회 재시도로 ROOT 확보(실패 시 파일 도구로 `~/Desktop/velog-posts` 확인, 둘 다 실패 시 "접근 불가 — 수거 중단" 보고 종료).
- `BASE=$ROOT/⟨프로파일: EXAM_DIR⟩/claude_ox_오답`. `$BASE/{오늘날짜}-claude_oxquize.md` 존재 시 "이번 주 노트는 이미 생성됨" 보고 후 종료. `$BASE/_ledger/build_ledger.py` 존재 확인 — 없으면 경로 오류이니 재탐색.

## 1. 안전망 수거 (Downloads → _inbox)
- Downloads 마운트에서 `⟨프로파일: RESULT_GLOB⟩` 패턴의 결과 JSON을 `cp -n`으로 `$BASE/_inbox/`에 복사. **이 시험의 패턴만** — 다른 시험 파일은 그 시험의 파이프라인 소관(교차 저장 금지).
- 패턴은 프로파일 값을 그대로 쓴다(`*오답_*` 형태 — 과목명 낀 변형 누락 실사고 교훈). `-RQ` 결과·브라우저 사본 `(1)`도 그대로 복사(원장이 사본 제거).
- Downloads 미마운트여도 종료하지 않는다 — "Downloads 미연결: 기존분 진행" 명시 후 계속(원장은 전체 이력 누적이라 무손실). 평일 파이프라인이 당일 수거를 이미 하므로 복사 0건은 정상.

## 2. 원장 갱신
- `cd "$BASE" && python3 _ledger/build_ledger.py --ingest`. exit 2(원천 0건)면 출력 그대로 보고 후 종료. 오류 은폐 금지.
- `⟨프로파일: 대시보드⟩`가 정의돼 있으면 이어서 실행(실패해도 계속하되 보고).
- 갱신된 `$BASE/_ledger/오답_원장.json`을 읽는다 — **이후 모든 수치·목록은 이 파일에서만**. 출력의 원천 수·누적 오답을 지난주 노트와 비교, 늘지 않았는데 이번 주 제출이 있었다면 무음실패 의심·원인 보고.

## 3. 기대치 검증 (무음실패 백신 — 반드시)
- 이번 주 수거 JSON의 날짜가 원장 `ledger[].dates`에 실제 등장하는지 대조(파일 수만 믿지 말 것).
- **데일리퀴즈 대조**: 지난 7일 `데일리퀴즈/20*.html` 각각에 결과 도착 여부 — 데일리 결과로 인정하는 것은 정확히 `⟨프로파일: 데일리 결과 파일명⟩`(± ` (N)` 사본)뿐, **`-RQ`는 데일리 신호가 아니다.**
- **오답퀴즈 대조**: 지난 7일 `오답퀴즈/20*.html` 각각에 `-RQ` 결과 도착 여부를 별도 줄 집계.
- 미도착이 있으면 "⚠️ 결과 미도착 N개: {목록} — 제출 화면의 '📋 결과 JSON 복사'로 _inbox에 넣어달라"를 **채팅 보고와 노트 양쪽에** 기재.

## 4. 주간 오답노트 생성 (원장 뷰)
- 저장: `$BASE/{오늘날짜}-claude_oxquize.md` (velog-posts 안. Downloads 아님). "지난주" = 원장 이벤트 중 날짜 접두가 지난 7일인 것.
- 구성(순서대로): ① 제목+인용블록(기간·제출·평균·지난주 오답 수 — 원장 통계) ② `## 🟦 과목명` 지난주 오답 상세(문제/정답/해설/함정 키워드, 2회+ 틀림은 `🔁 N회` 표기 후 맨 위 — 원재료는 지난주 JSON과 원장 samples, 추가·누락 금지) ③ `## 🎓 졸업·졸업후보` ④ `## 🔴 상습 경보` 표 ⑤ `## 🗓️ 다음 주 복습 큐` dueQueue 상위 8 표(망각위험 R 포함 — **평일 오답 재도전 퀴즈의 출제 원천**) ⑥ `## 📊 패턴 분석` 5분류 표(숫자 함정/의심병/주체·권한 혼동/단정 표현/비슷한 이름 쌍)+최대 적신호 1개 ⑦ `## 🔑 핵심 암기카드 5장` ⑧ `## 💡 콘텐츠 소재 후보 3` — 질문형 훅 1줄씩 ⑨ `## ✅ 기대치 검증` §3 결과(데일리/오답퀴즈 구분).
- 지난주 오답 0개(전부 만점 또는 데이터 공백 — 구분 명시)면 ②⑥⑦ 생략, 통계+졸업+검증만.
- 데이터가 아직 얇은 시험(원장 초기)은 있는 만큼만 채우고 "원장 초기 — N주 후 완전체" 1줄 명시.
