## §2. 정답(모범답) 문형 — 답안체 6규칙

정답은 **답안지에 그대로 옮겨 적을 수 있는 문장**만으로 구성한다. 이 퀴즈의 정답 = 현규가 시험장에서 쓸 문장의 원형이다.

1. **화자 = 수험생.** 해설자 요약체 금지 (§2-2 변환표).
2. **결론 선행.** 결론·당부를 묻는 문항은 첫 문장이 결론 단문 — 발문 어미와 문법적으로 호응한다("성립하는가?" → "성립하지 않는다.").
3. **조문은 문장 뒤 괄호**: "(형법 제21조 제1항)" — 낫표(「」) 금지(실제 답안 문체는 괄호형). 노트에 명시된 조문만.
4. **판례는 문형으로**: "판례는 ~는 입장이다" / "판례에 의하면 ~라고 한다". 판례 원문 인용은 홑따옴표(').
5. **포섭·종결 표지**: 사례형은 "사안의 경우 ~이므로/~인바," + "~라 할 것이다 / ~함이 타당하다 / ~하여야 한다".
6. **짧은 단문으로 끊는다** (실전에서 수정테이프 사용 불가 — 18호 §1-2). 일반 정답 2~4문장·260자 이내.

**학설은 쓰지 않는다** — 판례의 태도만 현출 (합격자 수렴, 18호 §2-2). 유일 예외: 판례가 취한 학설의 명칭 1개(예: 법정적 부합설)는 판례 문형 안에서 언급 가능.

### 2-2. 해설자체 → 답안체 변환표 (금지 → 전환)

| 해설자 요약체 (금지) | 답안체 (전환) |
|---|---|
| "판례는 법정적부합설에 따라 고의를 인정한다." | "판례는 법정적 부합설의 입장이므로, 발생한 사실에 대한 고의의 기수책임이 인정된다 할 것이다." |
| "~로 처리한다 / ~가 된다 / ~때문이다." | "~라 할 것이다 / ~함이 타당하다 / ~하여야 한다." |
| "치는 이르게 했다는 뜻이다." (사전체) | "치(致)란 일정한 결과에 이르게 하였다는 의미로, 결과적 가중범의 죄명에 사용된다." |
| 명사 나열 "주체, 객체, 행위, 결과, 인과관계." | "객관적 구성요건요소로는 ① 주체 ② 객체 ③ 행위 ④ 결과 ⑤ 인과관계가 요구된다." |

※ 목차순서형만 예외적으로 "① → ② → ③" 개조식 허용 — 목차 자체가 답안 형식이므로.

| sub | 정답 골격 |

| 판별식 | "양자는 ~인가에 따라 구별된다. ~이면 A로서 ~하고, ~이면 B로서 ~하다 할 것이다." |
| 목차순서 | "① → ② → ③의 순서로 검토한다." + 위치 이유 1문장(있으면) |
| 판례문구 | "판례는 ~는 입장이다." — 판례가 쓴 **포인트 문구**를 그대로 담는다(현출이 사활 — 18호 §2-4) |
| 용어정의 | "~란 ~를 말한다(조문)." |

**예시 (전부 형식 시연용 — 실제 출제 소재는 노트 한정)**

- 결론이유: q "甲은 乙을 살해할 의사로 폭탄 하나를 던져 乙을 포함한 30명을 사망하게 하였다. 甲의 죄수에 대한 결론과 그 이유를 기재하시오." → answer "상상적 경합에 해당한다. 1개의 행위가 수개의 죄에 해당하는 때에는 가장 무거운 죄에 정한 형으로 처벌하는바(형법 제40조), 사안의 경우 폭탄 투척이라는 1개의 행위로 수개의 살인죄가 성립하므로 과형상 일죄로 처리함이 타당하다." / keywords ["상상적 경합", "1개의 행위·수개의 죄(형법 제40조)", "가장 무거운 죄의 형", "과형상 일죄"]
- 요건개수: q "정당방위가 인정되기 위한 요건을 답안에 쓰는 순서대로 서술하시오." → answer "정당방위가 인정되기 위해서는 ① 현재의 부당한 침해 ② 방위의사 ③ 상당한 이유가 필요하다(형법 제21조 제1항)."
- 판별식: q "구체적 위험범과 추상적 위험범의 구별 기준을 밝히고, 그에 따라 포섭 목차가 어떻게 달라지는지 서술하시오." → answer "양자는 공공의 위험이 현실로 발생하여야 기수가 되는가에 따라 구별된다. 위험의 현실적 발생을 요하면 구체적 위험범으로서 위험 발생을 별도의 요건으로 포섭하여야 하고, 요하지 않으면 추상적 위험범으로서 행위 자체로 기수가 된다 할 것이다."
- 목차순서: q "친고죄·반의사불벌죄를 답안에서 논하는 위치를 목차 순서로 서술하시오." → answer "구성요건해당성 → 위법성 → 책임의 순서로 범죄 성립을 모두 검토한 다음, 소추조건으로서 친고죄·반의사불벌죄 해당 여부를 논한다."
- 판례문구: q "구체적 사실의 착오에 관한 판례의 태도를 답안에 현출하는 문장으로 쓰시오." → answer "판례는 법정적 부합설의 입장으로, 객체의 착오든 방법의 착오든 발생한 사실에 대한 고의의 기수책임을 인정한다."
- 용어정의: q "부진정 결과적 가중범의 의의를 답안 첫 문장으로 쓰시오." → answer "부진정 결과적 가중범이란 중한 결과를 과실로 야기한 경우뿐만 아니라 고의로 야기한 경우까지 포함하는 결과적 가중범을 말한다."

## §4. 미니답안형 상세 — 10점형 2단 골격

근거: 배점 스위치 "10~20점 소문항 = 2단(조문+판례 → 포섭·결론)" [18호 §2-3, 실증]. 서두 쟁점 정리는 쓰지 않는다(소배점에서 서두+결론 = 배점의 10~15%뿐).

```
[결론 1문장 — 발문 어미 호응]<br>
[법리: 요건 ①②③(조문) 1~2문장 + 판례는 ~는 입장이다 1문장]<br>
[사안의 경우 사실을 요건에 대입 → ~라 할 것이다]
```

- 분량 150~500자, `<br>`로 3문단 구분. 문항 목표 3~4분.
- 포섭은 **사안의 사실을 요건에 하나씩 대입** — 법리 복붙 후 "따라서 인정된다" 한 줄은 포섭이 아니다 [18호 §2-4].

**표준 예시**: q "甲은 어려서부터 자신을 지속적으로 성폭행하여 온 의붓아버지 乙이 잠든 사이에 乙을 칼로 찔러 살해하였다. 甲에게 정당방위가 성립하는지에 대한 결론과 그 이유를 기재하시오. (10점)" → answer "정당방위는 성립하지 않는다.<br>정당방위가 인정되기 위해서는 ① 현재의 부당한 침해 ② 방위의사 ③ 상당한 이유가 필요하다(형법 제21조 제1항). 판례는 지속적 침해 상태에서 침해의 현재성은 인정될 수 있으나, 잠든 사람을 살해한 행위는 사회통념상 상당성을 결여한다는 입장이다.<br>사안의 경우 乙의 침해는 현재성이 인정되나 甲의 살해행위는 상당한 이유를 결여하였으므로, 정당방위는 성립하지 않는다 할 것이다." / keywords ["정당방위 불성립(결론 선행)", "요건 3개(형법 제21조 제1항)", "현재성 인정·상당성 결여", "사안의 경우"]

**과목별 골격 변주** (해당 과목 노트가 생기면 적용):

| 과목 | 미니답안 골격 |
|---|---|
| 민법 | 유형 → 조문 → 요건 → (항변) → 판례 → 포섭 [실증 이0진 틀] |
| 형법 | 죄명 결론 → 구성요건(주체·행위·결과·인과) → 위법성·책임 중 문제되는 단계만 → 포섭 |
| 민소 | **결론 카테고리(소각하·청구기각·청구인용) 명시** → 법리 → 사안의 경우 → "법원은 ~판결을 하여야 한다" |
| 부등 | 의의 → 신청인 → 신청정보 → 첨부정보 → 등기관의 조치 (만능 목차) 중 발문이 묻는 단계만 |

## §6. keywords·expl 계약 (요약 — 계약 정본은 프로파일 v1.3)

- keywords = **논증 단계 채점 앵커**: [결론 단어]·[조문/요건]·[판례 핵심어]·[포섭 변수] 중 문항에 있는 것을 답안 등장 순서대로 2~4개. 자가채점 질문은 "내 답에 이 단계가 있었나"다.
- expl = 3문장 250자 유지: [정답 근거] → [메커니즘 1문장] → [**감점·함정 포인트** 1문장(§5에서)].

## §7. 역할 경계 (P4 가드 — 늘리지 않는다)

이 퀴즈의 역할은 **문형 각인 + 논점 인출까지**다. 완전 서술 연습은 주말 슬롯·순환 모의고사가 담당한다 — "연습은 키워드·목차 인출로, 완전 서술은 모의고사에서만" [실증 한0호, 18호 §5-4]. 미니답안형을 하루 2문 넘게 편성하지 않는다. 타이핑 퀴즈는 손글씨 답안 연습을 대체하지 못한다는 한계를 전제로 설계된 것이다.
