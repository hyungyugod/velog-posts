# 베이스_오답파이프라인 v1 — 시험 공통 (2026-08-25)

> 시험 무관 공통 메커니즘. 해당 시험의 프로파일을 반드시 함께 정독, `⟨프로파일: KEY⟩` 슬롯을 채운다. 충돌 시 프로파일 우선.
> 계보: 스케줄_프롬프트_오답파이프라인_v1(두 시험 통합판)을 단일 시험용으로 분리 — 이제 시험마다 자기 스케줄러로 독립 실행.

평일(월~금) 아침 실행. 이 시험 하나에 대해 ① 결과 JSON 수거 → ② 오답 원장 갱신 → ③ 오답 재도전 퀴즈 생성을 순서대로 수행한다.

**[실행 원칙] 오답 데이터는 결과 JSON·원장에 있는 것만 쓴다(지어내기 금지). 집계는 build_ledger.py가 한다. 다른 시험의 파일은 절대 건드리지 않는다 — 이 시험의 파일만 이 시험의 폴더로 간다. 시험 간 파일이 섞이면 그날 작업 전체가 실패다.**

## 0. 경로 (마운트 지연 대비 — 반드시 재시도)
- ⚠️ 워크스페이스 마운트는 늦게 붙는다. 첫 조회가 비어도 '부재'로 단정하지 말 것 (2026-07-27 사고 교훈).
```bash
for i in 1 2 3 4 5; do
  ROOT=$(find /sessions/*/mnt -maxdepth 2 -type d -name velog-posts 2>/dev/null | head -1)
  [ -n "$ROOT" ] && break
  echo "velog-posts 마운트 대기... ($i/5)"; sleep 5
done
DL=$(ls -d /sessions/*/mnt/Downloads 2>/dev/null | head -1)
BASE=$ROOT/⟨프로파일: EXAM_DIR⟩/claude_ox_오답; RQ=$ROOT/⟨프로파일: EXAM_DIR⟩/오답퀴즈
```
- 5회 후에도 ROOT가 비면 파일 도구로 `~/Desktop/velog-posts` 직접 확인, 그래도 실패 시 "velog-posts 접근 불가 — 전 단계 중단"을 보고하고 종료(엉뚱한 곳에 생성 금지).
- 밀린 과거 날짜분을 만들지 않는다 — 항상 오늘 하루치만.

## 1. 수거 (Downloads → `$BASE/_inbox/`)
- 패턴은 반드시 `⟨프로파일: RESULT_GLOB⟩`를 그대로 쓴다 (과목명이 낀 변형 `공인중개사_민법전범위_오답_*.json`을 놓친 실사고 교훈 — `*오답_*`가 핵심):
```bash
cp -n "$DL"/⟨프로파일: RESULT_GLOB⟩ "$BASE/_inbox/" 2>/dev/null
```
- 다른 시험 파일은 건드리지 않는다(그 시험의 파이프라인 소관).
- 브라우저 사본 `... (1).json`도 그대로 복사한다(원장이 사본을 제거한다). 오답 재도전 퀴즈의 결과(`*-RQ.json`)도 같은 패턴에 자동 포함된다 — 이게 졸업·재도전 판정의 원천이다.
- **Downloads는 읽기 전용** — 삭제·이동·수정 금지, `cp -n`만.
- Downloads 미마운트여도 종료하지 않는다 — "Downloads 미연결: 기존 _inbox 분만으로 진행"을 보고에 명시하고 계속한다.

## 2. 원장 갱신 (이 시험의 원장만)
```bash
cd "$BASE" && python3 _ledger/build_ledger.py --ingest
```
- `⟨프로파일: 대시보드⟩`가 정의된 시험이면 원장 갱신 성공 후 이어서 실행한다. 정의가 없으면 생략(정상 — 이식 안 한 시험).
- exit 2(원천 0건)는 원장 초기엔 정상일 수 있다 — 출력 그대로 보고하고 §3을 건너뛴다. 다른 오류도 숨기지 말 것.
- 갱신된 `$BASE/_ledger/오답_원장.json`을 읽는다. **이후 모든 수치·듀큐는 이 파일에서만 가져온다.** 다른 시험의 원장 교차 사용 금지(남의 원장으로 이 시험 퀴즈를 만들면 안 된다).

## 3. 오답 재도전 퀴즈 생성
### 3-1. 편성 판정 (기계적)
- `N = min(20, dueQueue 길이)`. **N = 0이면 오늘은 미생성** — "듀 0 — 오답퀴즈 없음" 한 줄 보고. 듀보다 많이 내려고 다른 원천을 끌어오지 않는다(FSRS 마감 도래분만이 원천이다).
- `$RQ/{오늘날짜}.html`이 이미 있으면 오늘 퀴즈는 생략(수거·원장은 이미 수행됨). 덮어쓰기 금지.
- 출제 대상 = dueQueue **상위 N개** (원장이 이미 상습 우선 → 망각위험 오름차순으로 정렬해 둠 — 재정렬 금지).
### 3-2. 문항 작성 (전 문항 재도전 표기)
- 근거 = 각 듀 항목의 원장 `samples`(원 문제·해설)와 이 시험의 학습 노트(`⟨프로파일: 신규 원천 규칙⟩`이 가리키는 폴더 — 트랙 분할 시험은 공유 노트 폴더). **여기 없는 내용 창작 금지.** 근거가 정말 부족한 개념은 건너뛰고 다음 듀 항목으로 대체하되 보고에 명시.
- **변형 출제**: 원 문제 복사 금지 — 같은 개념을 다른 각도·다른 숫자(긍정↔부정, 정의↔사례, 주체·기간 교체, 방향 뒤집기)로. 오답 보기는 정답과 '한 끗 차이', 더미 금지.
- 표기 3종 전 문항 필수: 문제문 맨 앞 `🔁 `, `conceptKey` = 듀 항목 값 **그대로 복사**(원장 매칭 키 — 변형 금지), `retryOf` = 같은 값. `src` = samples의 원 출처(없으면 "오답원장") + 끝에 `(재도전)`.
- 필드 계약: `{type, cat, q, opts, answer, expl, src, conceptKey, retryOf}`. 해설은 `[정답 근거]→[메커니즘 1문장]→[함정 1문장]` 3문장 250자 이내. 문자열에 큰따옴표(")·백틱 금지(따옴표는 ').
- **문항 형식**: `⟨프로파일: 문항 형식⟩` — 유형 구성·단답/객관식 판정·금지 유형·정답 균형 규칙은 프로파일이 정한다.
### 3-3. HTML 생성
- 템플릿 = `$RQ/_template.html` (데일리퀴즈 정본의 사본 — **JS·CSS 수정 절대 금지**, 데일리퀴즈 정본 원본도 건드리지 않는다).
- 토큰 교체만: `{{QUIZ_DATE}}` → 오늘날짜(두 곳) / `{{META_LINE}}` → "2026년 M월 D일 (요일) · 오답 재도전 N문항 · 듀 잔여 M개" (M = dueQueue 길이 − N) / `{{TAGS_HTML}}` → `<span class="tag">🔁 오답 재도전 N</span>` + 오늘 과목명 태그들 / 템플릿에 `{{ALERT_HTML}}`가 있으면 → 빈 문자열 / QUESTIONS 마커 사이에 배열 삽입.
- 저장: `$RQ/{오늘날짜}.html`
### 3-4. 검증 (통과까지 반복 — 기준 완화 금지)
```bash
cd "$RQ" && node -e '
const fs=require("fs");
const today=process.argv[1], base=process.argv[2];
const led=JSON.parse(fs.readFileSync(base+"/claude_ox_오답/_ledger/오답_원장.json","utf8"));
const due=(led.dueQueue||[]), exp=Math.min(20,due.length), keys=new Set(due.map(d=>d.conceptKey));
const html=fs.readFileSync(today+".html","utf8");
const Q=eval(html.match(/const QUESTIONS = (\[[\s\S]*?\n\]);/)[1]);
let fail=[]; const ok=(c,m)=>{ if(!c) fail.push(m); console.log((c?"PASS":"FAIL")+" — "+m); };
ok(!html.includes("{{"),"토큰 잔존 없음");
ok(Q.length===exp,"문항 수 = min(20,듀) = "+exp+" (현재 "+Q.length+")");
ok(Q.every(q=>q.retryOf&&q.retryOf===q.conceptKey&&q.q.includes("🔁")&&/\(재도전\)/.test(q.src)),"전 문항 재도전 표기(retryOf·🔁·src)");
ok(Q.every(q=>keys.has(q.conceptKey)),"conceptKey 전부 듀큐에 존재");
ok(Q.every(q=>q.q&&q.expl&&q.src&&q.cat&&q.type),"필수 필드");
const SA=Q.filter(q=>q.type==="단답"), MCQ=Q.filter(q=>q.type!=="단답");
ok(SA.every(q=>typeof q.answer==="string"&&Array.isArray(q.keywords)&&q.keywords.length>=2&&q.keywords.length<=4&&!q.opts&&q.exam==="2차"),"단답 계약(있다면)");
ok(MCQ.every(q=>Number.isInteger(q.answer)&&q.opts&&(q.opts.length===4||(q.type==="OX"&&q.opts.length===2))&&q.answer>=0&&q.answer<q.opts.length),"객관식 계약");
const ox=MCQ.filter(q=>q.type==="OX"); ok(ox.length<=Math.ceil(Q.length*0.3),"OX ≤30%");
const mc4=MCQ.filter(q=>q.opts&&q.opts.length===4);
if(mc4.length>=8){ const d=[0,0,0,0]; mc4.forEach(q=>d[q.answer]++); console.log("  정답 분포: "+d.join("/"));
  ok(Math.max(...d)-Math.min(...d)<=3,"정답 분산(최대-최소 ≤3)"); }
const sq=MCQ.map(q=>q.answer); let run=1,mx=1;
for(let i=1;i<sq.length;i++){run=(sq[i]===sq[i-1])?run+1:1;mx=Math.max(mx,run);}
ok(mx<=2,"같은 정답 3연속 없음 (최대 "+mx+")");
console.log(fail.length?"\n❌ "+fail.length+"건 — 수정 후 재실행":"\n✅ 통과");
process.exit(fail.length?1:0);
' "$(date +%F)" "$ROOT/⟨프로파일: EXAM_DIR⟩"
```
- FAIL 시: 보기 재배치·문항 교체·필드 보완 후 재실행. 통과 전 종료 금지.

## 4. 결과 루프 (안내용 — 실행 아님)
- 사용자가 오답퀴즈를 풀고 저장한 `*_오답_{날짜}-RQ.json`은 다음 평일 §1 수거에 자동 포함되어 원장의 졸업·상습·재도전 판정에 반영된다. 이 파일이 돌아오지 않으면 듀큐가 줄지 않는다.
- 카톡 푸시 페이로드는 만들지 않는다 — kakao_push.py는 데일리퀴즈 전용이며 **수정 금지**(중개사 시험 전 개조 금지 P-5).
