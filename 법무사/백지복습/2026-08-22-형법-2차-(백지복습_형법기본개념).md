# 백지복습 채점 — 2026-08-22 형법 기본개념

> 10분 제한 · 골격 선기재형(트리) · 원본 노트와 1:1 대조
> 채점 원칙: **개수가 아니라 구조**. 빠진 항목보다 "덩어리째 사라진 곳"이 진짜 진단이다.

---

## ② 회수율 궤적

| 덩어리 | 원본 항목 수 | 인출됨 | 상태 |
|---|---|---|---|
| ① 범죄성립 3단계 (골격) | 8 | 5 | 🟢 골격 성공 — 내부 구조가 빔 |
| ② 구성요건 내부 (객관/주관/초과주관) | 5 | 0 | 🔴 **덩어리째 소실** |
| ③ 정범·공범론 | 10 | 6 | 🟢 가장 잘 나온 구간 |
| ④ 범죄 유형론 (결과/형식·침해/위험·계속·자수) | 6 | 1 | 🟡 자수범만 생존 |
| ⑤ 시간적 적용범위 (행위시법·1조 2항·한시법) | 6 | 0 | 🔴 **덩어리째 소실** |
| 합계 | 35 | 12 | **34%** |

**첫 백지가 34%면 정상이다.** 커뮤니티·연구 양쪽 모두 초회차는 이 근처다. 문제는 숫자가 아니라 **아래 패턴**이다.

구조 진단 — 이게 채점의 본체

**① 전형적인 초두효과(primacy). 노트 앞부분은 살고 뒷부분이 통째로 날아갔다.**
①번 덩어리(노트 맨 앞)는 골격이 나왔고, ⑤번 덩어리(노트 맨 끝, 행위시법·1조 2항·한시법)는 **한 글자도 안 나왔다**. 실력 문제가 아니라 **인출 순서 문제**다. 사람은 항상 앞에서부터 꺼내고, 시간이 끝나면 뒤가 남는다.
→ **처방: 다음 백지는 노트 뒤에서부터 시작한다.** 또는 3덩어리 제목을 먼저 다 적어놓고(각 1줄) 그 다음에 살을 붙인다. 이 한 가지만 바꿔도 회수율이 크게 오른다.

**② "이름은 아는데 내용이 없는" 항목이 많다.**
구성요건해당성·위법성·책임성 세 단어는 다 적었는데, 각각이 **무엇을 판단하는 단계인지**는 위법성(조각사유)만 적혔다. 구성요건해당성의 정의("사실관계가 조문에 해당하는가"), 책임성의 정의("비난가능성 — 그 사람 입장에서")가 비었다.
→ 2차 답안에서 이 정의 한 줄이 목차 첫 줄로 그대로 나간다. **가장 먼저 메울 구멍.**

**③ 잘 나온 곳의 공통점: 예시가 붙어 있던 것.**
간접정범(간호사·의사), 자수범(위증죄), 14세 미만 — 전부 노트에서 **사례가 붙어 있던 항목**이다. 반대로 사례 없이 나열만 돼 있던 것(객관적 구성요건요소 5개, 행위지배 3종, 위험범 분류)은 전멸했다.
→ **처방: 나열형 항목에는 예시나 두문자를 강제로 붙인다.** 그게 다음 인출의 손잡이가 된다.

## ③ 남은 구멍 (최우선 재출제)

놓친 개념 — 덩어리별 정리 (내일 재인출 대상)

### ⓐ 구성요건 내부 구조 ★최우선
| 항목 | 내용 |
|---|---|
| 객관적 구성요건요소 | **주체 · 객체 · 행위 · 결과 · 인과관계** (5개) |
| 주관적 구성요건요소 | **고의** = 객관적 범죄사실의 인식 + 실행 의사 |
| 고의/과실 원칙 | 고의가 원칙. **과실은 처벌규정이 있는 경우에만** 처벌 ※ 어제 지적한 그 부분 |
| 초과주관적 구성요건요소 | **목적**(목적범) · **불법영득의사**. 필요한 범죄에서만 별도 검토 |
| 목적 ≠ 고의 | 목적은 의사·희망의 영역 — 구분해서 쓸 것 |

### ⓑ 3단계 판단의 나머지
| 항목 | 내용 |
|---|---|
| 구성요건해당성 정의 | 사실관계가 **조문에 해당하는가** |
| 불법 | **구성요건해당성 + 위법성 = 불법** |
| 책임성 정의 | **비난가능성**. 사람마다 다름 — 그 사람 입장이 되어 판단 |
| 친고죄 | 친히 고소해야 처벌 가능 |
| **답안 순서** | 3요소를 **다 쓰고 → 범죄 성립 → 그다음에** 친고죄·반의사불벌죄 논함 |

### ⓒ 정범·공범론에서 빠진 것
| 항목 | 내용 |
|---|---|
| 협의의 공범 | 교사범 + 종범(방조범) ↔ 정범 = 직접정범·간접정범·공동정범 |
| **행위지배 3종** | **실행지배** / **기능적 행위지배**(공동정범) / **의사지배**(간접정범) |
| 공범의 종속성 | 공범은 정범에 종속해 성립 → **답안은 언제나 정범부터 쓴다** |
| 제한적 종속형식 | 책임은 개별적 → **정범의 책임이 조각돼도 공범은 성립 가능** |
| 간접정범 뒷단 | 피이용자에게 과실이 있으면 **과실치사** 등 성립 가능 |

### ⓓ 범죄 유형론
| 구분 | 내용 |
|---|---|
| 결과범 vs 형식범 | 살인죄(사망 발생 필요) vs 폭행죄(유형력 행사만으로 충족) |
| 침해범 vs 위험범 | 보호법익 침해 정도 기준 |
| 구체적 위험범 | **공공의 위험 발생해야 기수** (자기소유 일반건조물방화) |
| 추상적 위험범 | 행위만으로 충족 (현주건조물방화) ※ 타인소유 일반건조물방화도 추상적 |
| **계속범** | 기수 후에도 범죄 계속 → **기수 이후에도 공범 성립 가능** ← 본인이 "엄청 중요" 표시했던 항목 |

### ⓔ 시간적 적용범위 (통째 소실)
| 항목 | 내용 |
|---|---|
| 원칙 | **행위시법**으로 판단 (현행법 아님) |
| 예외 | 형이 가벼워지면 **피고인에게 유리한 신법** 적용 (1조 2항) |
| 위임입법 변경 | 형벌규정 자체의 위임입법이 바뀐 경우 → **바로 1조 2항 적용** (전동킥보드 사례) |
| 다른 규정 변경 | **형사법적 관점의 변화**가 있어야 1조 2항 적용 (법무사법 개정 사례 → 관점 변화 아님 → 처벌 대상) |
| 한시법 | 유효기간 내 처벌 의도가 있으므로 **행위시법으로 처벌** |

      ├── [총론] ─ 범죄 성립 3단계 ── 하나라도 탈락 → 즉시 무죄, 뒤는 쓰지 않는다
      │      │
      │      ├─ 1. 구성요건해당성  = 사실관계가 조문에 들어맞는가        ✅이름만
      │      │     ├─ 객관적 : 주체·객체·행위·결과·인과관계              ❌

      │      │     └─ 초과주관 : 목적 · 불법영득의사  (필요한 죄만)      ❌
      │      │
      │      ├─ 2. 위법성       = 위법성조각사유가 있는가                ✅

      │      │

      │
      └── [각론] ─ 보호법익 기준으로 편제 → 법무사는 개인적 법익 中 재산죄  ✅


행위자 분류 ── 기준 = 행위지배 ✅
   │
   ├─ 정범 ┌─ 직접정범
   │       ├─ 간접정범   : 사람을 도구로 (의사→간호사)   → 의사지배      ✅예시

   ▸ 공범의 종속성 → 답안은 반드시 정범부터                              ❌
   ▸ 제한적 종속형식 → 정범 책임 조각돼도 공범 성립                       ❌
   ▸ 자수범(위증죄) → 직접 실행해야 정범, 간접정범 불가                   ✅


시간적 적용범위                                                      ❌ 전멸
   원칙: 행위시법
     └ 예외(1조 2항): 형이 가벼워지면 신법
          ├ 형벌규정의 위임입법 변경 → 바로 적용

          └ 한시법 → 행위시법으로 처벌

## ⑦ ⚠️ 확인 필요

확인 필요 3건 (내가 판독 못 했거나 애매한 것)

1. **방조범 옆 메모** — "편의○에서 ○ 대신 사례금"으로 읽히는데 판독 불가. 무슨 예시였는지 본인 확인.
2. **자수범 옆 "정범이라고 답안을 써야한다"** — 방향 확인 필요. 자수범에서 **직접 실행한 자**가 정범이고, **배후자는 정범이 될 수 없다**(교사범은 가능). 어느 쪽을 적은 건지 다음 회차에 명확히 쓸 것.
3. **책임성 아래 괄호** — "(마련되어 있)"으로 읽히는데 불명확.
