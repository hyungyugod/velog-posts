# 법무사 AI 학습 스택 설계서 v1.2 — 학습계획 보고서

> **전제**: 로드맵 v7(노션, 2026-08-22)이 학습계획의 정본이다. 이 문서는 v7을 바꾸지 않는다 — v7의 각 블록(FSRS 데일리·기출 루프·글쓰기 메뉴·유지 트랙·월말 회고)에 AI 도구를 꽂는 **엔진 설계서**다.
> **근거**: 내부 자산 분석(F)·AI 학습 근거 조사(G)·합격수기 전수조사(원자료 A~E) — 전부 `리서치원자료_2026-08/`에 보관. 계획(Fable)–조사(Opus 2기)–**검증 2라운드(Opus, 총 치명 12건 적발)**–재설계 사이클로 작성. v1.1 = 1차 검증 반영, **v1.2 = 2차 검증(램프업 결함·백로그 처방 무효·19호 의존 등) 반영 최종본** (개정 내역 §10).
> **한 줄 요약**: 새로 짓는 게 아니라 **공인중개사에서 검증된 엔진(원장·듀큐·데일리퀴즈·수거·대시보드)을 법무사 네임스페이스로 완전 분리 이식**하고, 2차 논술용으로는 **15호 md 오답로그를 정본으로 유지한 채 집계·경보만 자동화**한다. 화려한 신설은 검증에서 대부분 잘렸다 — 잘린 이유가 이 문서의 절반이다.

## 0. 직언 3개

**① 지금 중개사 루프가 끊겨 있다 — 새 시스템 논의 전에 이것부터.**
대시보드 실측: 8/20·8/21 퀴즈 미제출(streak 0), 오답 원장 듀 백로그 **91건**. 중개사 37회 D-70 시점이다. 이 패턴(엔진은 정교한데 사람 루프가 끊김)이 법무사에서 재발하는 것이 이 설계의 1번 리스크고, 그래서 첫 신설 기능은 화려한 뭔가가 아니라 **경보의 실행 주체**(§3-1·3-6)다. 당장 할 일(2차 검증 반영 — 원장이 인정하는 경로로): **8/23(일)** 주말 퀴즈 정상 응시·제출 재개 + 8/23·24·25 사흘간 "듀큐 상위 30건 재도전 세트"를 세션에서 1일 1세트 생성·풀이하고 **채점 JSON을 수거 규약 형식으로 저장**(그래야 월요일 수거가 원장을 실제로 갱신한다 — 눈으로만 복습하면 백로그는 1건도 안 줄어든다). 목표는 91→0이 아니라 **백로그 ≤30 진입**. 이건 제작이 아니라 공부다.

**② "AI가 1시간을 1.5시간으로 만든다"는 가설은 조건부로만 참이다 — 그 조건이 이 설계의 전부다.**
근거 조사(G): AI 튜터가 학습이득을 약 2배로 만든 실험(하버드, 전문가 스캐폴드 전제)이 실존하는 동시에, **AI가 답을 대신 주는 순간 시험 성적이 대조군 대비 -17%로 뒤집힌 RCT(PNAS, 터키 고교)**도 실존한다. 주의: 법학 논술형·성인 자기주도 수험생 대상의 직접 근거는 아직 없다(G의 외적 타당도 한계) — 그러니 "AI로 1.5배"는 확신이 아니라 **설계로 만들어야 할 목표**다. 갈림길은 도구가 아니라 구조: "AI가 문제를 내고 → 내가 먼저 답하고 → 채점받는" 구조면 증폭기, "모르면 바로 물어서 답 얻는" 구조면 마이너스. 15호 §0("AI가 먼저 쓰면 인풋")이 이미 정답이다 — 이 설계는 그 원칙을 모든 도구에 강제한다.

**③ 자동 생성 콘텐츠의 오류 혼입은 확률이 아니라 통계다 — 그런데 자동 검증의 손이 닿는 범위는 좁다.**
한국 변호사시험 벤치마크(KCL, arXiv 2512.24572) 기준 자료 없이 묻는 Claude는 객관식의 40~45%를 틀리고, 원문을 줘도 오류율은 0이 아니다(상용 법률 AI도 환각 17~33%). 1년치 데일리퀴즈는 수천 문항 — 게이트 없인 오류 수백 건이 각인된다. **단, 검증 라운드 실측 결과 법제처 API·law.go.kr은 이 자동화 환경에서 네트워크 차단**이라(16호 §5 "AI 자동 조회 불가"가 여전히 참) 자동 대조는 불가능하다. 그래서 방어선은 세 겹의 현실적 조합이다: ⓐ원문 첨부 기반 생성(P-2) ⓑ결정론 검증 스크립트 + "(원문 확인 필요)" 태그 잔존 grep 검사 ⓒ**조문·수치의 최종 대조는 사람**(기존 L-3 발행 체크 그대로 — 이 규칙은 자동화로 대체되지 않는다).

## 2. 목표 아키텍처

```
[인풋]                      [엔진]                          [루프]
강의 노트 (velog-posts/법무사/*.md)
기출 원문 PDF (빌드-0에서 조달)      ┌ 데일리퀴즈-법무사 (평일 아침, 11/2~)
2차 순환 문제·모범답안         ──▶  │  문항계약 v2 + 램프업 모드 + 회귀 세트
손글씨 답안 사진 (저장소 밖 폴더)     │  └ 검증: 결정론 단언 + 태그 grep + 미제출 경보 내장
                               ├ 오답 원장-법무사1차 (FSRS-6, 듀큐, 동적 캡)
                               │  └ 주간 수거-법무사 (일 21:00 자동) → 원장 갱신
                               │     + 15호 주간 지표 표 + 이탈 트리거 T1~T5 계측
                               ├ 논술 트랙 (정본 = 15호 md 오답로그, 자동화는 집계만)
                               │  └ 손글씨 첨삭 세션(대화형) → 로그 append → grep 편수
                               ├ 공식카드 덱 (16호 상태기계, 역인출은 세션에서)
                               └ 대시보드: 이중 D-day(1차·2차)·streak·백로그·편수 게이지
[가드레일] P-1~P-6 · 개정법 필터(19호 런타임 참조) · 사람 육안 대조(L-3 불변)
```

**1차용 축(객관식 원장)은 이식, 2차용 축은 "15호 수동 시스템 + 집계 자동화"다.** 2차 훈련의 본체가 대화형 인출(15호 7단위)인 이상, 자동화가 대체할 수 있는 건 기록·집계·경보뿐이라는 게 검증의 결론이다(F 격차①).

## 3. 도구별 상세 설계

### 3-1. 데일리퀴즈-법무사 (이식 + 개조) — 1차의 심장
원본 v4 골격(문항계약 v2·듀큐 재도전·정본 템플릿·node 검증) 유지, 개조 목록:
- **과목 쿼터**: 균등 → 문항수 비례 가중(민법 8/민집 7/부등 6/상법 6/공탁 4/헌법 4/상등 3/가족 2, 40문 기준). 미진도 과목 자동 제외·재배분. Phase A에는 당일·어제·그제 단원 가중(v7 재풀이 루프 정합).
- **유형 쿼터**: 계산 4문 폐지 → 판례결론형 12(결론을 가른 변수 지적) / 일반 14 / 조합 7 / OX 5 / 사례포섭 2. **검증 단언도 함께 교체**: `T("계산")` 단언 3종 삭제 → 판례결론형 단언 신설(F P5 지침).
- **램프업 모드 (콜드스타트 해결 — 2차 검증에서 재설계)**: 단계를 날짜가 아니라 **원천 존재 조건**으로 정의한다(결정론·자기모순 불가).
  - **발사일 = 11/3(화)**: 데일리퀴즈는 전일 노트가 원천이므로 Phase A 첫 학습일(11/2 월 저녁) 다음 날 아침이 첫 발사다. 11/2 이전 노트 0건 문제 소멸.
  - 단계 1 (조건: 장기복습 원천 없음): **총 30문** = 재도전 0~8(법무사 원장이 비었으면 0 — 그만큼 신규 확대) + 신규. 유형 쿼터 30문 스케일 고정: 판례결론 9 / 일반 11 / 조합 5 / OX 4 / 사례 1. 노트가 부족한 첫 주는 **기출 직행 보충**(당일 진도 단원의 기출 원문에서 — P-2 원천 ②).
  - 단계 2 (조건: 파일명 날짜 ≤ 오늘−14일인 법무사 노트 ≥ 3건 — 달력상 11/16 무렵): 장기복습 +10문 = **총 40문**, 유형 쿼터 40 기준 완전 적용.
  - 단계 3 (조건: 데일리퀴즈 HTML이 오늘−33~−27 창에 존재 — 달력상 12월 초): 한달전 복원 +10문 = **총 50문 완전체**.
  - 검증 단언은 단계를 **원천 존재로 판정**해 기대 문항수·쿼터를 산출한다(단계별 기대치 명시 — P-4가 램프업 구간에도 성립).
- **출제 원천 순위**: ①본인 노트(최근 7일) ②기출 원문 PDF(P-2 — 조달은 빌드-0) ③검증 승급 공식카드. 노트·기출에 없는 내용 출제 금지.
- **개정법 필터 — 19호 런타임 참조**: 개정 목록을 스킬에 복제하지 않고(드리프트 방지) 실행 시 `ai-guidelines/20_프롬프트-라이브러리/19_법무사_개정법워치_v1.md`의 §2 표를 **직접 읽어** 해당 개념에 `⚠ 20XX 개정` 자동 부착·구법 기출 필터. **19호는 프로젝트 지식파일로만 존재했으나 2026-08-22 로컬 사본을 위 경로에 배치 완료**(2차 검증 N1 해소). 분기 갱신 규약: **로컬 파일이 단일 정본**, 갱신 후 프로젝트 지식에 재업로드(기존 조립완성본 워크플로와 동일).
- **미제출 경보 내장 (검증 치명③ — 경보의 실행 주체)**: 스킬 실행 첫 단계에서 제출 신호를 확인, 2일 연속 미제출이면 **문제지 최상단 경보 배너 + 카톡 푸시 문구에 "⚠ 2일 미제출·백로그 N건" 삽입**. 에스컬레이션: 3일째 = 일요일 수거 리포트 최상단 경보 + 월말 회고 의제 자동 추가. **선행 조건(빌드-0 ④)**: 평일 퀴즈의 실행 위치와 "제출 신호"의 소스(채점 JSON 저장 경로 — 대시보드가 8/20·21 미제출을 이미 알았으므로 신호는 존재한다)를 현황 문서화로 확정한 뒤, 빌드-1 드라이런에서 경보 오작동을 실측한다. 실패 채널(배너·푸시)이 무시된 8/20 사례의 교훈: 경보의 최종 수신처는 본인이 매주 반드시 여는 화면(일요일 수거 리포트·월말 회고)이다.
- conceptKey: `과목 단원-요지`(F P2 스타일), 시험 구분은 subject 필드·글롭이 담당(중복 방지).
- 템플릿: 법무사판 파생본(정본 v4는 불가침) + 목표시간 표시(문항수×72초 — 1차 시간압박 감각, F 미도입 지적 반영. 강제 타이머는 아님).
- FSRS 동적 캡 (검증 치명⑥ 수정): `max_interval = clamp((1차 시험일 − 오늘)/2, 30일, 120일)` — **초반(D-300)엔 120일로 풀어 적체를 막고**(F §3-7의 실제 지적), 말기(D-60)엔 30일로 조인다. 1차 시험일 상수는 2027-08-28(추정)로 시작, **2027-04 공고 확인 알림의 액션에 "이 상수 갱신" 포함**. 1차 종료 시 1차 원장 동결이므로 음수 구간 없음.

## 7. 성공 지표 (월말 회고 자동 공급)

1. **루프 생존율**: 데일리퀴즈 제출률 ≥90%. 2일 연속 미제출 = **퀴즈 내장 경보**(§3-1) — v7 경보 매트릭스의 "아웃풋 미달 최우선"과의 관계: 이 지표는 시스템 KPI 1번이지 학습 우선순위 1번이 아니다. **학습 우선순위는 v7 그대로(손글씨 아웃풋이 왕)**.
2. 듀 백로그 ≤30건(초과 시 신규 축소·재도전 확대 — 자동).
3. 손글씨 편수: v7 게이트(6/30 20편→1차 전 30→2차 80) — grep 집계.
4. **분리 지표 2개**: 퀴즈 정답률(객관식, 주간 산출) / 역인출 성공률 70%(공식카드 `마지막 역인출` 기반, 15호 정의 그대로).
5. 이탈 트리거 T1~T5 계측치(13호): 완강률·주간 훈련 시간·1차 모의 과목군 40점 축·반복코드 수 — 주간 지표 표에서.
6. 태그 잔존 0건 발행 + **본인 투입 시간(제작+운영 합산) 월 3h 이내**(P-6과 동일 기준) — 회고에서 기록(자기보고임을 명시, 외부 검증란 병행).
7. 듀 백로그 규칙의 실체(§7-2의 "자동" 명세): 백로그 >30이면 다음 퀴즈부터 재도전 쿼터 8 고정 + 신규 5문 축소, ≤30 복귀 시 원상. `DUE_BACKLOG_WARN=30`으로 코드 상수 통일.

## 8. 남은 불확실 (정직하게)

- 한국어 손글씨 전사 정확도 — 정량 자료 부재(G). **2월 파일럿이 결정**(95% 미만이면 전사 폐기).
- 데일리퀴즈-법무사의 판례결론형 문항 품질 — 9월 드라이런+회귀 세트 20문으로 실측, 오류율 기준(예: 표본 검수 오류 5% 초과 시 원천 축소) 사전 합의 필요.
- 평일 데일리퀴즈의 실행 위치(이 PC 스케줄 목록에 부재 — 다른 기기/스킬 호출 여부) — 빌드-0 ④에서 현황 문서화로 확정.

## 9. 이 설계가 의도적으로 자동화하지 않는 것

백지 인출(23:30 종이) · 손글씨 완전서술 · 조문 원문 대조 · 시험장 루틴. 이유는 하나다 — **이 네 가지가 시험 그 자체이기 때문이다.** 자동화는 이것들을 둘러싼 기록·반복·경보를 맡는다. 도구가 인출을 대신하는 순간 -17%의 세계로 넘어간다(G).
