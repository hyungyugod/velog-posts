## 0. 방법론과 신뢰도 고지 (먼저 읽을 것)

### 무엇을 어떻게 확인했나
- **검색엔진(WebSearch)**으로 개별 영상 URL을 수집했다. `youtube.com/results` 직접 fetch는 JS 렌더링이라 무의미하므로 시도하지 않았다.
- 수집한 모든 영상 ID를 **YouTube oEmbed API**(`youtube.com/oembed?url=...&format=json`)로 개별 조회했다. 이 API는 JS 없이 JSON을 반환하므로 **영상 제목과 채널명은 100% 실측 확인값**이다.
- 이 검증 과정에서 **검색엔진 스니펫의 오류를 1건 적발**했다. 검색 결과가 `jnEv7-qxAwE`를 "법무사 8개월 만에 합격한 공부법 Part 1/3"로 표기했으나, oEmbed 실측 결과 실제로는 **"누구보다 오랜 버틴 결과, 끝내 해냈다! 33년 만에 법무사 시험 합격한 사연ㅣ은퇴레시피"(건강IN으로 채널)** 라는 전혀 다른 영상이었다. → **검색 스니펫만 믿으면 안 된다는 실증.**

### 신뢰도 등급 (본문에서 이 표기를 따름)
| 표기 | 의미 |
|---|---|
| **[확인·oEmbed]** | 영상 제목·채널명. YouTube API 실측. 확실함. |
| **[확인·스니펫]** | 검색엔진이 영상 설명문/본문을 인용한 내용. 출처는 실제 영상 메타데이터이나 요약 과정에서 왜곡 가능성 있음. |
| **[추정·제목]** | 제목에서만 추론한 내용. **영상을 본 적 없음.** 실제 내용은 다를 수 있음. |
| **[미확인]** | 업로드 시기·영상 길이 등. 검색 스니펫에서 스쳐 지나간 값으로 교차검증 안 됨. |

### 확인 못 한 것 (정직하게)
- **영상 길이**: 단 1건도 확인하지 못했다. oEmbed는 duration을 반환하지 않고, 검색 스니펫에도 없었다. 전 항목 미기재.
- **업로드 시기**: 약 40%만 검색 스니펫에서 확보. 교차검증 불가하여 **[미확인]** 표기.
- **영상 실내용**: 스크립트 미확보. "확인된 내용" 칸이 비어 있는 항목은 **제목만 보고 분류한 것**이다.
- **조회수·좋아요**: 전 항목 미확보.
