# 📌 1. 형법 케이스 해결방안 — 죄수론과 답안 골격

## 1-1. 죄수론 — 상상적 경합 vs 실체적 경합

> 💡 죄의 개수는 "행위의 개수"로 센다. 이 하나가 죄수론 전체의 갈림길이다.

### 1) ★★ 두 경합의 구분

| 구분 | 상상적 경합 | 실체적 경합(경합범) |
|---|---|---|
| 조문 | 「형법」 제40조 | 「형법」 제37조~제39조 |
| 행위 수 | 1개 | 수개 |
| 죄수 성질 | 실질적 수죄 · 과형상 일죄 | 실질적·과형상 모두 수죄 |
| 처벌 원칙 | 흡수주의 — 가장 무거운 죄의 형 | 가중주의 원칙 + 흡수·병과 병용 |
| 형 가중 | 없음 | 장기·다액의 1/2 가중(합산 초과 금지) |

### 2) ★★ 사안별 결론

| 사안 | 결론 |
|---|---|
| 무면허 + 음주운전 | 상상적 경합 (운전행위 1개) |
| 1개의 폭행으로 공무집행방해 + 상해 | 상상적 경합 |
| 1발로 수인 살해 | 상상적 경합(동종 상상적 경합) |
| 1개의 문서로 수인 명예훼손 | 상상적 경합 |
| 주거침입 후 절도 | 실체적 경합 (행위 2개. 다만 야간주거침입절도는 결합범 = 일죄) |
| 강도 + 강간 | 별도 행위 → 실체적 경합 (요건 갖추면 강도강간죄로 결합) |

> 📐 공식 | 행위 1개 → 상상적 경합(제40조) ∧ 흡수주의 / 행위 수개 → 실체적 경합(제37조~제39조) ∧ 가중주의
> ⚠ 예외: 수개 행위라도 법이 하나의 구성요건으로 결합해 두면(결합범) 일죄 — 예) 야간주거침입절도, 강도강간

## 1-2. 불가벌 유형 2종

> 💡 별죄를 세지 않는 이유가 서로 다르다 — 하나는 "너무 가벼워서", 하나는 "이미 다 평가돼서".

### 1) ★ 불가벌적 수반행위

- 한 구성요건의 불법내용이 주된 범죄에 대하여 **경미하기 때문에** 고려되지 않는 경우
- 예) 살인죄와 의복손괴 — 사람을 찌르며 생긴 옷의 손괴는 별도로 세지 않는다

### 2) ★★ 불가벌적 사후행위

- 주된 범죄에 의하여 획득한 위법한 이익을 **사용·처분하는 사후행위**가 이미 주된 범죄의 불법에 의하여 **완전히 평가**되었기 때문에 다른 범죄를 구성하지 않는 경우
- 예) 절도죄 → 손괴죄 (훔친 물건을 부순 경우), 현금을 훔쳐 사용한 경우
- 어원: 不(아닐 불) + 可(옳을·가할 가) + 罰(벌할 벌) = "벌할 수 없는"

> 📐 공식 | 수반행위 = 불법이 **경미** → 흡수 / 사후행위 = 불법이 **이미 평가됨** → 흡수
> ⚠ 예외: 사후행위가 **새로운 법익을 침해**하면 별죄가 성립한다 (원문 확인 필요 — 필기에 미기재, 판례 법리 확인 후 보강할 것)

## 1-3. 논증 공식과 구성요건 판별

> 💡 답안은 창작이 아니라 IRAC 4칸 채우기다.

### 1) ★ 법학의 논증공식 — IRAC

- **I** 문제점/쟁점 (issue)
- **R** 조문/판례 (rule)
- **A** 사안포섭 (application)
- **C** 사안의 해결 (conclusion)

### 2) 사기죄 vs 절도죄 — 처분행위 판별

- 두 죄는 **처분행위**로 구분된다
- 절도죄 = 침탈당한 경우 / 사기죄 = 처분행위로 직접 넘겨준 경우

### 3) ★★ 형법 문제 4대 체크사항

- ① 친족관계 ② 시간이 야간/주간 ③ 위험한 물건 ④ 주거침입 여부

> 📐 공식 | 재산범죄 판별식: **피해자가 스스로 넘겼는가?** → YES 사기죄 / NO 절도죄
> ⚠ 개정 주의: ①친족관계는 **친족상도례 개정(2025.12 — 프로젝트 지침 기준)** 으로 실익이 달라졌다. 구판 기출·문제집 지문 그대로 쓰지 말 것 (개정 워치 19호 대조 필요)

## 1-4. ★★ 답안 문장 템플릿 — 첫 문장과 끝 문장은 고정이다

> 💡 형법 답안은 무조건 첫 문장과 끝 문장에 "죄"를 언급해야 한다.

### 1) 문장 순서 (그대로 외운다)

1. **첫 문장** — "갑의 ~의 행위와 관련하여 ~죄(여러 죄면 '또는'으로 연결)의 성부가 문제된다."
2. **죄의 정의** — "A죄라 함은 (조문에서 형벌 전까지 베끼기)한 경우에 성립하는 범죄이다."
3. **구성요건 해석** — "~경우라 함은 ~을 의미한다."
4. **쟁점 좁히기** — "사안의 경우 ~의 인정 여부가 문제된다."
5. **판례** — "판례에 의하면 ~사안에서 ~이 문제되었던바, ~라는 이유로 ~라고 판시하였다."
6. **평가** — "~한 이유로 판례의 태도가 타당하다."
7. **위법성 · 책임 검토**
8. **결론** — 죄와 **죄수**를 밝히고 끝낸다

> 📐 공식 | 첫 문장(성부 제기) → 정의 → 해석 → 쟁점 → 판례 → 평가 → 위법성·책임 → 결론(죄 + 죄수)
> ⚠ 예외: 시간이 붕괴하면 2·5·8만 남긴다 — 정의·판례·죄수는 마지막까지 버리지 않는다

## 1-5. ★★ 케이스 답안 목차 — 유형별 골격

| 목차 | ① 갑 단독 · 단순 사실관계 | ② 갑 단독 · 별개 사실관계 | ③ 갑·을 공범 · 단순 사실관계 | ④ 갑·을 공범 · 별개 사실관계 |
|---|---|---|---|---|
| Ⅰ | 쟁점의 정리 | 쟁점의 정리 | 쟁점의 정리 | ⚠️ (원본 확인 필요) |
| Ⅱ | A죄의 성부 | 제1행위에 대한 검토<br>1. A죄의 성부<br>2. B죄의 성부 | 갑의 죄책<br>1. A죄의 성부<br>2. B죄의 성부 | ⚠️ (원본 확인 필요) |
| Ⅲ | B죄의 성부 | 제2행위에 대한 검토<br>1. C죄의 성부<br>2. D죄의 성부 | 을의 죄책<br>1. A죄의 교사범의 성부<br>2. B죄의 교사범의 성부 | ⚠️ (원본 확인 필요) |
| Ⅳ | C죄의 성부 | 사안의 해결 | 사안의 해결 | ⚠️ (원본 확인 필요) |
| Ⅴ | 사안의 해결 | — | — | — |

> 📐 공식 | **대분류를 무엇으로 잡을 것인가** — 행위자 1명 ∧ 사실관계 1개 → **죄명별** 병렬 / 행위자 1명 ∧ 행위 시간적 분리 → **행위별**(제1·제2행위) 대분류 후 그 안에 죄명 / 행위자 2명 → **사람별**(갑의 죄책 → 을의 죄책) 대분류
> ⚠ 예외: 공범 사안은 **정범(갑) 먼저, 공범(을) 나중** — 을의 교사범 성부는 갑의 정범 성립을 전제로 하므로 순서를 뒤집으면 논리가 무너진다

## 1-6. ★★ 서술 규율

- 답안 작성 시 **한 번에 하나의 범죄만** 검토한다. 한 명씩, 단독 범죄인 것처럼 쓰고 붙인다
- **단정적 표현**을 쓴다. 만연체 금지 — 딱딱 끊어 쓴다

> 📐 공식 | 1문단 = 1범죄 = 1결론. 문장은 종결형으로 끊는다
