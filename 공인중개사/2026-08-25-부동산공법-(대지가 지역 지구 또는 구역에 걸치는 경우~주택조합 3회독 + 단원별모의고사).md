# 📌 1. 대지가 지역·지구·구역에 걸치는 경우

## 1-1. 걸침의 원칙
> 💡 원칙은 "과반 지역 기준", 단 방화지구와 녹지지역은 예외다.

### 1) 방화지구 — 조금만 걸쳐도 전부 적용
- 건축물이 방화지구에 일부만 걸쳐 있어도 **건축물 전부에 방화지구 규정**을 적용한다.
- 예) 건물 모서리 1㎡만 방화지구에 물려도 건물 전체가 방화 규정 대상.

### 2) 녹지지역 — 과반이 아니라 각각 적용
- 분할된 각 지역 중 **녹지지역이 있으면 과반 규정을 쓰지 않고 각각 따로 적용**한다.
- 이유: 녹지를 보존하기 위해서다.

# 📌 2. 면적 산정 기준

## 2-1. 건축면적 · 바닥면적 · 연면적
> 💡 건축면적=하늘에서 본 그림자, 바닥면적=층마다 재는 실내, 연면적=바닥면적의 총합.

### 1) 건축면적
- **외벽 중심선** 기준 수평투영면적.
- 산입하지 않는 것: 지하주차장 경사로, 보행통로, 차량통로.
- 예) 지하주차장으로 내려가는 램프는 그림자가 져도 건축면적에 안 들어간다.

### 2) 바닥면적
- **층마다** 계산하며, **구획 중심선** 기준 수평투영면적.
- 바닥면적을 전부 합치면 = 연면적.
- 벽·기둥 구획이 없는 건물(주유소 등)은 **지붕 끝에서 1m 물러난** 수평투영면적으로 한다.

### 3) 바닥면적에 산입하지 않는 것
- 노대(발코니): 노대면적 − (가장 긴 외벽에 접한 길이 × 1.5m) 만큼만 산입 → 계산 결과 남는 부분만 들어간다. *(원문 확인 필요 — 아래 §확인 필요 참조)*
- 필로티
- 문화재 보호시설, 리모델링 시 외벽에 부가하는 단열재 등
- 기계실·전기실·어린이놀이터 등 **함께 쓰는 시설**
- 승강기탑·계단탑·장식탑
- 예) 1층을 기둥만 세워 주차장으로 비운 필로티는 바닥면적 0.

### 4) 연면적 (용적률 산정용)
- 용적률 산정 시 연면적에서 **제외**: 지하층, 지상층의 주차장, 대피공간, 피난안전구역 등.
- 예) 지하 3층 주차장은 실제로는 존재하지만 용적률 계산에선 없는 셈 친다.

# 📌 3. 높이 산정과 높이 제한

## 3-1. 옥탑의 높이 산입
> 💡 옥탑이 건축면적의 1/8 이하면 "12m 초과분만" 높이에 넣는다.

### 1) 1/8 이하인 경우
- 옥상의 승강기탑·계단탑·망루·옥탑 등 **수평투영면적 합계 ≤ 건축면적의 1/8** → **12m를 넘는 부분만** 건축물 높이에 산입.
- 예) 옥탑 높이 14m, 1/8 이하 → 2m만 높이에 더한다.

### 2) 1/8 초과인 경우
- 탑의 **높이 전부**를 건축물 높이에 더한다.

## 3-2. 높이 제한 완화·정북방향 일조
### 1) 공개공지 완화
- 공개공지를 설치하면 **높이제한·용적률을 1.2배** 완화.

### 2) 정북방향 일조 확보 (전용주거·일반주거지역)
- 높이 **10m 이하** 부분 → 정북 인접대지경계선에서 **1.5m 이상** 이격.
- 높이 **10m 초과** 부분 → **높이의 1/2 이상** 이격. (건물이 비스듬해지는 이유)
- 예외: 일반상업·중심상업지역, 2층 이하이면서 높이 8m 이하인 건축물은 채광(정북일조) 적용 배제.

## 3-3. 가로구역 단위 높이 규제
- 街(거리 가) + 路(길 로) = 도로·거리 / 區(구분할 구) + 域(지경 역) = 경계로 나뉜 범위.
- **가로구역 = 사방이 도로로 둘러싸인 블록 하나** (도시계획의 block 개념).
- 개별 필지가 아닌 가로구역 기준으로 규제하는 이유: **블록마다 스카이라인을 통일**하기 위해서다.

# 📌 4. 특별건축구역 · 건축협정

## 4-1. 특별건축구역
> 💡 "개보접자"는 못 들어가고, 들어가면 건폐율·용적률·높이가 풀린다.

### 1) 지정 불가 지역 — 개보접자
- **개**발제한구역 / **보**전산지 / **접**도구역 / **자**연공원

### 2) 지정 효과
- 지정·변경 시 **관리계획 의제** 있음. 단 **용도지역·지구·구역의 지정 및 변경은 의제되지 않는다.**
- 적용 배제: 건폐율, 용적률, 높이제한, 조경, (대지 안의) 공지.
- **5년 이내 착수**하지 않으면 지정이 흔들린다.

### 3) 통합적용 대상 — 딱 3개
- **공원 · 부설주차장 · 미술작품**
- 건축물의 높이제한은 통합적용이 아니라 **배제**할 수 있는 규정.

## 4-2. 건축협정
### 1) 동의 요건
- 협정 체결: 소유자·지상권자 등 **전원 합의**
- 운영회 설립: **과반수 동의** / 폐지: **과반수 동의**

### 2) 통합적용 대상 — "건조한 부대지개"
- **건**폐율 / 대지의 **조**경 / 부설주차장 / 대지와 **도**로의 관계 / **지**하층의 설치 / **개**인하수처리시설
- ※ **대지 안의 공지는 해당하지 않는다.** (특별건축구역과 헷갈리는 포인트)

# 📌 5. 이행강제금 · 분쟁조정

## 5-1. 이행강제금
> 💡 소형 주거용은 반값, 영리·상습은 가중 "해야 한다".

### 1) 감경
- 연면적 **60㎡ 이하 소형 주거용 건축물**은 **1/2** 감경.

### 2) 위반 유형별 곱하는 비율
| 위반 유형 | 비율 |
|---|---|
| 건폐율 초과 | 0.8 |
| 용적률 초과 | 0.9 |
| 무허가 | 1 |
| 무신고 | 0.7 |

### 3) 가중
- 영리 목적 위반·상습 위반 → **100% 범위에서 가중 부과해야 한다.** (할 수 있다 ✕)

### 4) 공법의 대전제
- **공법은 다 요식행위** — 문서로 해야 한다.

## 5-2. 건축분쟁전문위원회
- **국토교통부**에 두는 기구, **민간 vs 민간** 분쟁 조정.
- 행정청과 다툴 때는 → 행정심판.
- 위원장·부위원장은 국토교통부장관이 위촉, 위원 **15명 이내**.
- 위원 임기 **3년** (보통은 2년이라 여기가 특이) *(원문 확인 필요)*

# 📌 6. 주택법 — 주택의 종류와 시설

## 6-1. 세대구분형 공동주택
> 💡 소유는 하나, 공간만 둘. 그래서 구분소유 불가.

### 1) 기본 성질
- **구분소유 불가** → 한 사람 소유이므로 **경량구조 경계벽**을 설치한다.

### 2) 세대수 한도
| 근거 | 한도 |
|---|---|
| 사업계획승인 받아 건축 | 주택단지 전체 세대수의 **1/3** 이내 |
| 공동주택관리법상 허가·신고 | 전체 세대수의 **1/10** 이내 **그리고** 해당 동 세대수의 **1/3** 이내 |

## 6-2. 도시형 생활주택
- 단지형 연립주택·단지형 다세대주택은 **5개층까지** 건축 가능.

## 6-3. 부대시설·기간시설
- **지역난방공급시설**은 단지 밖이므로 부대시설 ✕ → **냉난방공급시설**이 부대시설.
- 암기 "**가스통 난방**": **가스**시설·**통**신시설·**지역난방**시설은 **주택단지 안의 기간시설을 포함**한다.

## 6-4. 공공택지에서 빠지는 것
- 주택법은 **도시정비사업을 공공사업으로 보지 않는다** → 공공택지 ✕
- **환지 방식으로 시행하는 도시개발사업**도 공공택지 ✕

## 6-5. 리모델링과 공구
| 구분 | 내용 |
|---|---|
| 리모델링 | 대수선 또는 사용검사일부터 **15년** 경과한 공동주택을, 주거전용면적 **30% 이내**(85㎡ 이하면 40%) 증축 + 기존 세대수의 **15% 이내** 세대수 증가 |
| 대수선 리모델링 | **10년** 경과로도 가능 |
| 공구 | 착공신고·사용검사를 **별도로** 할 수 있는 구역. 공구별 **300세대 이상**. 사업계획승인은 전체가 한 번에 받으므로 공구별 분리 대상이 아니다 |

# 📌 7. 주택법 — 사업주체와 주택조합

## 7-1. 등록사업자
### 1) 결격사유
- 등록말소된 후 **2년**이 지나지 않은 자.

### 2) 자본금 요건
- 법인 5억 이상 / 개인 10억 이상 *(원문 확인 필요 — 아래 §확인 필요 참조)*

### 3) 6개층 이상 건설
- 최근 **3년간 300세대** 이상 건설 실적이 있으면 6개층 이상 주택 건설 가능.

## 7-2. 주택조합
> 💡 조합원 모집 → 2년(종결) → 설립인가 → 3년(해산) → 사업계획승인.

### 1) 공동시행
- 세대수를 증가하지 않는 리모델링 주택조합을 **제외**하면, **국가 제외 / 공공기관 포함** 등록사업자와 공동 시행 가능.

### 2) 총회 출석요건
- 중요한 사항은 **100분의 20 직접 출석**.
- 중요한 사항 = **money(자금)·임원선임·해산·시공자·업무대행자 선정** 등.

### 3) 직장주택조합
- 국민주택을 공급받기 위한 직장주택조합은 **신고**로 설립하며, 조합원은 **무주택자만** 가능.

### 4) 기간 규칙
| 항목 | 기한 |
|---|---|
| 조합원 추가모집 승인·변경인가 신청 | **사업계획승인 신청일까지** |
| 설립인가 후 사업계획승인 신청 | **2년 이내** |
| 조합원 모집 후 종결 여부 결정 | 2년 |
| 설립인가 후 해산 여부 결정 | 3년 |

### 5) 청약 철회
- 철회는 **발송한 날**에 효력 발생 → **7일 이내** 가입비 반환 요청 → **10일 이내** 반환.

### 6) 리모델링 주택조합 (1개 동)
- 한 개 동을 리모델링하려면 그 동의 **구분소유자 및 의결권의 2/3 이상** 결의.

### 7) 자격 판단 기준일
- 추가모집·충원되는 조합원의 자격요건 충족 여부는 **조합설립인가일이 아니라 조합설립인가 신청일** 기준.

## 7-3. 주택법 문장 감각 두 가지
- 주택법에서의 취소는 **"취소할 수 있다"**로만 쓴다 → 주택경기가 불안정하기 때문에 재량으로 열어둔다.
- **상속은 만능** — 공법은 상속을 잘 규제하지 않는다.

# 📌 8. 사업별 시행 절차 비교

## 8-1. 네 법의 흐름
> 💡 도시개발은 "환지"가 괄호로 끼어들고, 정비법은 "관리처분"이 분수령이다.

### 1) 도시개발사업
개발계획수립 → 개발구역지정 → 시행자선정 → 실시계획 → **실시계획인가·고시** → (환지계획인가) → 사업시행 → (환지예정지지정) → 준공검사 → (환지처분공고) → (환지등기)

### 2) 도시 및 주거환경정비법
기본방침 → 기본계획 → 재건축진단 → 정비계획 및 정비구역 지정 → 시행자지정 → 사업시행계획작성 → **사업시행계획인가·고시** → 분양통지·공고 → 분양신청 → 관리처분계획수립 → **관리처분계획인가·고시(사용·수익 정지)** → 사업시행(철거) → 준공인가 → 소유권이전고시 → 이전등기

### 3) 건축법
건축주 → 설계 → 건축허가·신고·협의 → 착공신고 → 착수 → 안전관리예치금 → **사용승인**

### 4) 주택법
사업주체 → **사업계획승인** → 착수 → **사용검사** → 주택의 공급 → 주택의 리모델링

### 5) 한 줄 구분 실익
- 건축법은 "**사용승인**", 주택법은 "**사용검사**" — 용어를 바꿔 내는 것이 단골 함정.
