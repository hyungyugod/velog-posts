# 토지경제와 지리경제~감정평가론 복습 + 단원별모의고사
- 수확체감의 법칙: 토지처럼 고정된 생산요소에 노동·자본 같은 가변 요소를 계속 추가 투입하면, 처음엔 산출이 늘지만 일정 시점부터 한계생산(추가 1단위 투입당 늘어나는 산출)이 점점 줄어드는 현상을 말한다.
- 차액지대론에서 수확체감의 법칙 -> 토지를 넓히는 대신 **같은 땅에 노동·자본을 더 투입(집약적 경작, intensive margin)**해도 되는데, 이때 추가 투입의 한계생산이 체감하기 때문에 결국 어느 지점에서는 "땅을 늘리는 것"과 "투입을 늘리는 것"이 같은 한계비용에서 만난다 → 이 균형점이 지대 크기를 결정
- 리카도 차액지대론에서 지대는 비용이 아니라 경제적 잉여이다.
- 알론소는 튀넨의 입찰지대를 도시에 적용시켰다. 농작물별로 -> 산업별로
- 지대이론 - 리카도, 마르크스, 튀넨, 알론소
- 도시지역이론 - 버제스 동심원이론, 호이트 선형이론, 해리스올만 다핵심이론
- 공업입지이론 - 베버최소비용이론, 뢰쉬 최대수요이론
- 상업입지이론 - 크리스탈러의 중심지 이론, 넬슨 소매입지이론
- 동심원이론 -> 튀넨의 토지이용구조를 도시구조에 적용시킴, 시카고시, 주거지역 중심 생태학적분석 (노중통), 침입경쟁천이
- 선형이론 -> 호이트는 시카고 시를 넘어 142개 도시를 분석 -> 주거지는 도로를 따라 소득계층별로 형성됨 -> 도로주변에는 고소득층이 있게됨 (좋은 접근성)
- 다핵심이론 -> 동종활동이 모이므로 기능별로 구역이 나뉨
- ! 최소비용이론 -> 비용이 최소인 지점이 공장의 최적입지이다. -> 수송비, 노동비, 집적이익, 등비용선(수송비 동일지점), 원료지수(원료가 1보다 크면 원료가 무겁다. -> 무거운쪽에 가까히 위치)
- 뢰쉬는 수요측면에서 기업은 시장의 확대가능성이 가장 높은 지점에 위치해야한다고 보았다.
- 크리스탈러 중심지 -> 시장이나 매장이 있으면 중심지(제공지), 배후지, 중심지의 계층화 
- ! 최소요구치 = 중심지가 존속하기 위한 최소한의 고객 수 (손익분기점)
- 최소요구치범위 = 중심지가 존재하는 범위
- ! 재화의 도달범위 = 중심지 기능이 미치는 한계거리
- 최소요구치 범위 < 재화의 도달범위 이어야한다.
- 소매입지이론 -> 특정점포가 최대 이익을 얻기위해 어떤 장소에 입지해야하는가
- 동일수급권 -> 대상부동산과 대체경쟁관계가 성립하는 비슷한 부동산이 모여있는 지역으로 인근지역(대상 속한지역)과 유사지역(대상 속하지 않은 지역)을 모두 포함한다.
- ! 부동산의 가치라고 하면 현재가치를 의미한다.
- ! 시장가치는 통상적 시장에서 신중한 거래들을 통해 가장 성립될 가능성이 높은 가액이다.
- 부동산가격이 최고가 되기 위해서는 외부 상황에 적합해야하고(적합의 원칙) 내부의 구성환경이 균형을(균형의 원칙) 맞춰야한다.
- 비교방식은 시장성의 원리에 기초한 방식이다. (ex. 공시지가기준법)
- ! 적산법은 초대경비 : 기초가액 x 기대이율 = 기대수익, 기대수익 + 경비 = 임대료
- ! 주부6단 : 주택 -> 한국부동산원 -> 공시기준일 이후 분할합병시 6월 1일이나 다음 해 1월 1일에 개별주택가격 결정공시
- 수익방식에 의한 대상부동산의 시산가액 (試(시험할 시) + 算(계산할 산) + 價額(가격·가치). 직역하면 "시험 삼아 계산해본 가액") -> 수익가액
- 10년 후 주택구입에 필요한 10억원을 마련하기 위해 어떤 이자율로 적금액을 산정한다면 이는 감채기금계수를 활용한다.
- ! 회계적이익률법은 따로 시간적인 효과를 고려하지 않고 지금 당장 장부에서 간단하게 투자수익률등을 판단하는 방법으로 장부에서의 연평균 순이익 / 연평균투자액을 해서 구하는 비할인법이다. 이렇게 재무제표나 현금흐름표에서 뽑은 지표로 투자를 판단하는 비할인법을 비율분석법이라고 한다.
- 세후지분투자수익률은 세후현금흐름/지분투자액으로 구한다.
- 총자산회전율은 투자된 총자산에 대한 총소득의 비율이다.
- ! 부채비율은 부채/자기자본으로 구하며 건물가격이 4억이고 저택저당대출이 2억이라면 나머지 2억이 자기자본이된다. 또 부채건전성이란 대출이 상환가능한 수준으로 관리되고 있는지를 따진다.
- 부채서비스액은 매월 또는 매년 지불하는 이자지급액과 원금상환액의 합계를 의미한다.
- ! 순소득승수는 총투자액(부동산가격) / 순영업소득을 의미한다.
- 부동산금융이 일반금융과 다른점으로는 담보기능과 감가상각 및 차입금이자에 대한 세금감면이 있다. ('이상'한건 빼준다.)
- ! 자본환원률은 순영업소득을 수익률로 나눠서 부동산의 가치를 구할때의 수익률을 의미한다. 따라서 자본환원률에는 수익률의 특성인 시간의 대가와 위험의 대가가 전부 반영되어있다.
- 실효이자율은 실질적으로 부담하는 이자율로 수수료등을 포함한 금액을 말한다.
- ! 총부채원리금상환비율 dsr은 연간원리금상환 / 연소득 비율을 의미한다.
- n: 설립보고서를 작성하여 국장에 제출하는 것은 실질이 있는 자기관리부동산투자회사만 설립등기일로부터 10일이내에 한다.
- n: 부동산투자회사는 매분기말 현재 총자산의 100분의 70이상은 부동산이어야한다. (80이상이 3가지)
- 발기설립은 소수발기인이 주식을 전액인수해 회사를 안정적으로 키우고 인가받은 뒤에 유상증자, 공모를 통해 일반투자자를 받도록 설계한 것을 말하며 부동산투자회사는 발기설립의 방법으로해야한다.
- 프로젝트금융해서 부외금융효과를 얻는 쪽이 시행자이고 공사를 직접하는 쪽은 시공자이다.
- 컨소시엄구성방식은 시행사, 금융기관 건설사등이 공동출자해서 프로젝트를 진행하는 것을 의미한다.
- 학교시설 및 문화시설과 같이 사용료를 징수하기 어려운 시설은 btl방식을 주로 활용한다.
