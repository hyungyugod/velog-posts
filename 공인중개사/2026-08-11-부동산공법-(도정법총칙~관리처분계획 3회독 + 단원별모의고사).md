# 도정법총칙~관리처분계획 3회독 + 단원별모의고사
- 재건축사업만 지상권자를 토지등소유자에 포함하지 않는다. 주거환경개선사업과 재개발사업만 도로를 넓힐 필요가 있고 이미 재건축사업은 기반시설이 양호하기 때문이다.
- 도정법 기본계획에서 생활권을 주면 개단을 생략할 수 있다. (개략적인 범위 및 단계별 정비사업 추진계획을 생략할 수 있다.)
- 대도시시장이 아닌 시장이 기본계획을 수립하면 도지사의 승인을 받아야한다.
- 보통 면적변경은 10%가 경미한 사항인데 도정법 기본계획은 20%가 경미한 사항이다. 건폐율 용적률도 20%이다. 아래 계획부터는 다시 10%로 바뀐다. 
- 철거할 건물들은 재건축진단을 실시하지 않을 수 있다.
- 정비구역에서는 도시개발법과 달리 대수선이 행위제한대상이 아니다.
- 비닐하우스 등의 간이공작물은 정비구역에서 허가를 받을 필요가 없다. (치우는데 0.5초)
- 정비구역지정 해제 기준: 예정일 -> 3년x -> 구역 -> 2년x -> 추진위원회 -> 2년x -> 조합설립인가 -> 3년x -> 사업시행계획인가신청
- 추진위원회 양쪽이 2년인걸 기억하자 나머지는 3년, 조합이 아닌 토지등소유자가 시행하면 5년
- 재건축 사업은 관리처분계획으로 건축물을 공급하는 방법까지만 가능하다. 재개발사업은 여기에 환지방법도 가능하다.
